# アップロードされた近畿切り出し画像による再処理

状態: 未完成のレビュー候補。本番へは未反映。

入力は `source_original.png`（139 × 184、RGBA）。アップロードを無加工で保存し、SHA-256を `source_manifest.json` に記録。
既存画像の (658,608) にRGBが完全一致することを検証した。ただしアルファは一致しないため、今回の入力のアルファを使用した。画像を生成AIで描き直したり、既存画像の透明度へ置き換えたりしていない。

画像座標の対応を維持するため、計算上のみ切り出し範囲外を透明として扱う。基盤陸地・海岸線は不変。前回の中部候補と承認済み本番データは変更していない。

## 成果物

- `kinki/qa/01_actual_warp.png`: 画像側の変形結果と正本海岸（桃色）。
- `kinki/qa/02_raster_vector_overlay.png`: 上記と国境線候補（水色）。
- `kinki/qa/05_source_trace.png`: 画像座標でのトレース確認。
- `kinki/border_review_candidate.gpkg`: 別レイヤーの画像座標線・変換線・表示線・正本海岸・対応点。
- `kinki/review_layer.json`: 海岸IDと正本点列、国境線候補。未確定の面・所属海岸区間は空。
- `kinki/registration_report.json`: 位置合わせ・未確定接点と墨線支持のない区間の記録。
- `kinki/validation_report.json`: 部分成果物の保全・変換検査。政治領域の完成を保証しない。

線が細い、交点が密集している、あるいは抽出用経路の設定が不十分な箇所で分断が残っている。原因をすべて原画像の解像度に帰してはいない。接点の経路修正、海岸への局所位置合わせ、中国地方との共有線の統一、面化検査が必要。自動処理で欠けを推測補完していない。

再生成: `python tools/prepare_kinki_uploaded_crop.py`

入力の切り出しは地理的位置を特定するのに有効だが、新しい細部情報は増えない。高解像度の原図またはベクターが提供されれば、密集した国境線の判読に利用できる。
