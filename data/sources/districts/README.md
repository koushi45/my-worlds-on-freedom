# 郡の調査用資料キャッシュ

工程A・Bで参照したHTMLを `pages/` に保存する。各HTMLに対応するJSONは取得URL、取得日時、応答ヘッダー、SHA-256を記録する。取得失敗を含む一覧は `retrieval_log.json`。ウェブ経由のみで確認できた資料は編集側の資料台帳に閲覧経路を明記する。

国・郡の比較一覧は『旧国・旧郡境界データセット』（CODH作成）「幕末明治地勢地図境界データ」（人間文化研究機構作成）を加工。DOI: 10.20676/00000454。本文に示されたライセンスはCC BY-NC 4.0。HTMLメタのCC BY表記と相違するため、本文側の制限を記録した。商用配布の許諾は取得していない。

別の資料にこの条件を流用しない。個々の利用条件・利用した箇所・対象時期は [資料台帳](../../editorial/districts/sources.json) を参照。

工程A・Bでは地図画像・ポリゴン・タイルを取得していない。工程Cでは `stage_c/` に後世の比較GeoJSON697件と和泉の元禄図の画像応答を追加した。原資料と補正結果は別ディレクトリに保存し、個々のURL・ハッシュ・条件は同ディレクトリの資料一覧に記録する。[工程Cの記録](../../../docs/districts/STAGE_C.md)を参照。キャッシュと編集台帳は調査用で、既存のexport除外対象に保存する。未調査の個別文書や郡詳細ページを閲覧済みとは記録しない。
