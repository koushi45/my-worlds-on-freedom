# 四国・中国地方：画像変形と旧国境レビュー

作成日: 2026-09-10。状態: **未承認のレビュー候補**。
本番マップ、承認済み九州、Windowsビルドは変更していない。

## 対象

- 四国本島: 伊予・讃岐・土佐・阿波の4国、共有境界5本。
- 中国地方の本州部分: 長門・周防・石見・安芸・備後・備中・備前・美作・出雲・伯耆・因幡の11国。東端の但馬・播磨との線を含め23本。
- 隠岐や瀬戸内海の島など、離島所属は未確定。推測で割り当てていない。

## 実施内容

1. 九州と同じ入力 `data/work/political/coast_alignment_v2/source_rgba.png` のアルファチャンネルを墨線として使用。透明画素のRGBノイズは使用しない。
2. 四国31点、中国32点の海岸対応点を置き、地域別の区分線形変換で**画像全体を逆写像リサンプリング**。海岸だけを描き替える処理ではない。
3. 原画像座標上で共有国境の墨線を補助トレースし、画像と同じ三角形変換を適用。
4. 海岸は基盤の `coastline_id` と点列をそのまま参照。区間端だけを線上補間する。
5. 共有国境と正本海岸のグラフを面化し、国名シードで閉じた面を特定。基盤陸地と積集合を取る。隙間の自動配分はしない。
6. 太い交点のトレースで発生した往復・枝部分は、両国の面を実際に分ける元の線分だけ残して除去。元の変換線もGPKGに保存。

## 自動検査

`python tools/verify_chugoku_shikoku_registration.py`

両地域とも以下に合格。詳細は各 `validation_report.json`。

- 基盤陸地、海岸線、入力画像、承認済み九州のSHA-256不変。
- 4国/11国の有効な面、重複・隙間は浮動小数点許容値 1e-6 game px² 未満。
- 表示国境が隣接国の外周と一致（距離許容値 1e-7 game px）。
- 海岸IDの点列が正本と完全一致、区間参照が一致。
- 変換三角形の反転・重複なし、往復変換誤差 1e-6 入力px 未満。

再生成: `python tools/build_chugoku_shikoku_registration.py --region all`

## レビューで残る点

海岸の細部は完全一致していない。岬・湾・半島の形の差を比較画像で確認してから承認すること。対応点上の補間一致は精度保証ではないため、レポートには対応点を1点ずつ除いた予測誤差も記録した。この誤差は入力pxではなく8192ゲーム座標単位であり、以前の入力px目標に合格したとは扱わない。

四国西端の海岸接続は海側の末端を切除。備後・備中の湾付近では、半島側への誤接続を避けるため画像側の対応先を本土海岸上で調整した。いずれも正本は不変で、変更はspecとレポートに記録し未承認のまま。

この画像は概略の令制国図であり、特定の戦国年の大名領・厳密な史実境界を保証しない。国名の同定には取得済みCommons原画像も照合した。既存の出典・ライセンス記録は保持し、本番採用時には帰属文も同梱する。
