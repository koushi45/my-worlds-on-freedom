# 近畿・中国地方の国境線エディター

本番マップで「近畿の国境線を編集」または「中国地方の国境線を編集（未確定）」を選択してください。

## 操作

- **追加**: 始点と終点を左クリックすると直線1本を追加。曲線は複数の短い直線で表現できます。既存の水色線の端点と海岸には画面上8px以内で吸着します。
- **範囲削除**: 上部のモードを切り替え、左ドラッグで四角形を作ります。マウスを離すと、内側の水色線だけが削除されます。横断する線は外側を残して分割します。
- **枠の確認**（整形済みの中国地方）: モードを切り替えて国の内側をクリックすると、編集線から作った国の枠を黄色で表示します。枠も未確定です。線を追加・削除した後は、古い枠を表示せず、JSONの書き出しと枠の再作成を案内します。
- 中ボタンドラッグで移動、ホイールで拡縮、Fで全体表示。追加モードでは左ドラッグでも移動できます。
- Esc／右クリックで未確定の始点・削除範囲を取消。
- Ctrl+Zで元に戻す、Ctrl+Yでやり直し。最大100操作。
- 「変形した参考画像を表示」は任意。参考画像の黒い線は画像の一部で、削除対象ではありません。通常はオフです。

## 保存して渡す

「JSONを書き出す」から保存先を選択し、近畿は `kinki_border_edits.json`、中国地方は `chugoku_border_edits.json` を保存してください。自動保存も地方ごとに独立しています。
そのJSONをこの会話に添付してください。画像やスクリーンショットではなく、JSONが必要です。

JSONには編集後の線の全点列、8192正本座標の仕様、元草稿と基盤ファイルのハッシュを格納します。ズーム・移動などの表示変換は保存しません。削除は「編集後の全線を置き換える」形式なので、消した部分も再現できます。

「JSONを読み込む」で編集の続行ができます。同じ基盤・草稿に対応するファイルのみ読み込みます。
変更はユーザーデータ領域にも自動保存されます。ただし他の人へ渡すには必ずJSONを書き出してください。

## 保護対象

海岸と九州・四国の確定線は別の読み取り専用データです。範囲に含まれても削除されず、追加線が確定済み地域の内部に入る場合も拒否します。エディターの草稿は本番の政治領域には登録されません。

近畿・中国地方は現時点では未確定の線編集です。エクスポートしたJSONを基に、次の工程で交点分割、共有線整理、正本海岸との接続、閉じた面の構築、隙間・重複の検査を行います。閉じていない箇所があれば、推測で国を割り当てず確認します。
