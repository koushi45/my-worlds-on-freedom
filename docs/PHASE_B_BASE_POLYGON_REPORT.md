## ゲーム対象範囲の抽出

Natural Earth Landは物理陸地データであり、国別所有属性を持たない。日本部分の選択を再現可能にするため、ポリゴンの代表点を次の固定コリドーで判定した。

- 北海道
- 東日本
- 四国・瀬戸内海
- 西日本
- 九州・西方諸島
- 伊豆諸島

正確な座標範囲はマニフェストの`selection.corridors`を正とする。南西諸島と小笠原諸島はゲーム対象外としてコリドー外にした。コリドー内でもAlbers正積投影で2km²未満の島を62面除外した。

抽出条件は原本の座標を切断するクリップではない。各原本ポリゴンを全体のまま採用または除外している。

## 必須属性

`japan_land`の全154フィーチャに次の属性を設定した。

| 属性 | 実装 |
|---|---|
| `feature_id` | 固定UUID名前空間と原本版・原本部品IDから生成した永続ID |
| `part_class` | 本州のみ`mainland`、その他は`island` |
| `source_id` | `ne_10m_land:{原本フィーチャ}:{原本部品}` |
| `source_version` | `5.1.1` |
| `edit_status` | `unchanged` |
| `edit_note` | `source coordinates unchanged` |

全IDは一意で、欠損値はない。

## 8192×8192ゲーム座標

承認前に派生レイヤーを作成しない規則に従い、GeoPackageには`japan_land`だけを収録している。`japan_land_game_8192`は未生成であり、承認後に正本から生成する。

変換は次の順で固定した。

1. WGS 84から日本全域用のLambert正角円錐投影へ変換する。
2. 固定範囲`128°E,30°N–146°E,46°N`を使用する。
3. 縦横比を保持する単一倍率で8192×8192へ収める。
4. 外周に128pxの最低余白を設ける。
5. 北を上、画面Y軸を下向きにする。

投影文字列、固定範囲、倍率、オフセット、計算式は、再現可能な変換仕様としてマニフェストの`game_transform`へ保存した。現在は`materialized: false`である。プレビュー画像は検証用であり、ゲーム用派生レイヤーではない。

## 以後の規則

- `japan_land`を直接手作業で上書きしない。
- 修正が必要な場合は、修正指示、修正前後差分、根拠を保存して再生成する。
- 海岸線、地形マスク、クリック判定、LOD、地方タイルは必ず`japan_land`から派生させる。
- 検証ゲート1の明示承認まではゲーム用派生レイヤーを生成しない。
- 承認後に生成する`japan_land_game_8192`は正本へ逆変換してはならない。
- Natural Earth Minor Islandsや別の海岸線を暗黙に混合しない。
