# 自家部隊の自動操作

自家の部隊をクリックし、部隊パネルの「自動：手動」を押す。占領または戦闘と、停戦中ではない敵対家を選んで「命令」を押す。実行中はボタンに命令の種類を表示し、対象家と進軍・制圧・安定化・帰還などの状態をその下に表示する。同じボタンから変更または解除できる。地図での移動・経由点指定・ドラッグ経路・帰郡命令は自動操作を解除する。

## 占領

指定家が支配する奉行所のうち、到達でき、往復と制圧の兵糧を確保でき、周辺の敵戦力が過大でない郡へ進軍する。日次で制圧し、獲得した郡の統治安定度が100%になるまで駐留した後、次の奉行所を選ぶ。他家の奉行所を攻略目標にはしない。略奪は自動実行しない。

## 戦闘

指定家の部隊のうち、自軍の戦力が周辺敵軍の合計の1.25倍以上となる相手を選ぶ。戦力は人数×（0.5＋大将・副将の平均武勇÷30）で評価し、地形補正は使わない。到達までの移動日数が最も短い相手を追撃し、既存の弓射撃・接近戦で攻撃する。対象の移動・損耗に合わせて日次で再選定する。戦闘命令中は奉行所・城の制圧で停止しない。

経路は各隣接タイルへの実際の移動日数を重みにしたA*探索で求める。距離だけで選ばず、道路、平地1〜1.5日、山地1.5〜2.5日、川1.5〜5日と通行不可地形を反映する。勝敗評価と経路の移動時間は別々に計算する。探索を日次に分割し、道路編集・領主変更時には経路キャッシュを破棄する。自家・対象家・同盟家以外の奉行所や施設を途中で通過しない。

## 帰還・保存

CPUと同様に、命令時の兵数の40%未満、腰兵糧15日未満、帰還日数＋10日以下の兵糧で帰還する。周辺敵軍が優勢、制圧に必要な兵糧が足りない、攻略・攻撃できる対象がない場合も帰還する。停戦・同盟などで指定家との敵対が解消した場合も帰還する。帰還中は新しい占領を開始しない。帰還経路が確保できない場合は、部隊パネルに手動指示が必要と表示する。

セーブ形式23に命令種別・対象家・命令時の兵数・帰還状態・追撃対象・表示状態を保存し、読み込み後も続行する。探索途中の作業データは保存せず、再計算する。旧形式の移行は行わない。
