# インフラの効果

インフラはLv.1〜10。整備費は現在のレベル×金銭100。

- 金銭・兵糧収入：Lv.1を基準に、1段階ごとに基本収入の5%を加算する。Lv.10では1.45倍。
- 防御：整備後のインフラレベルが郡の防御レベルになる。
- 人口増加数：毎月の基本増加数を現在人口の0.1%とし、収入と同じインフラ倍率を掛ける。Lv.10では現在人口の0.145%／月。

人口増加には研究「大名介入」の1.15倍も掛け、最後に整数へ四捨五入する。人口の上限は現在のセーブ形式に合わせて20億人。人口0の郡は自然増加しない。

毎月1日の収入計算後に開発・人口増加を行う。9月の兵糧収入も人口増加前に計算する。人口とインフラは既存の保存項目を使い、読み込み後も同じ式で増加数を求める。

郡の人口欄に月間増加数を表示し、郡の整備操作と一括管理の説明に3つの効果を記載する。
