# 郡奉行所の制圧と占領後の安定化

2026-10-04：案3を実装。奉行所の防御を削る旧処理を、日次の制圧率と獲得後の統治安定度へ置き換えた。

## 奉行所の制圧

- 部隊が敵対・中立家の奉行所タイルへ到着すると、そこで進軍を止め制圧を開始する。中立家への攻撃では開戦する。同盟・停戦中の家には開始できない。
- 制圧率は郡に保存し、到着時点では0%。毎日の処理で一度だけ進める。同じ家の停止中の部隊を合算する。別部隊への交代で進捗は失われない。
- 日次進捗は `min(50, 20 × sqrt(兵数 / 1000) × 統率係数 / 防御係数)` ポイント。統率係数は兵数で加重平均した `0.75 + 大将統率 / 60`。防御係数は `1 + (郡の防御＋建築効果−1) × 0.05`。
- 1,000人・統率15・防御1で5日が基準。大軍でも最低2日。制圧作業による兵の損害はなく、野戦・射撃と兵糧不足による損害は従来どおり。
- 奉行所の中心から隣接タイル中心までの距離以内に敵部隊がいると進捗を停止する。移動中の敵も実際の位置で判定する。同盟部隊は妨害しない。
- 制圧開始家を固定し、同盟軍には進捗を加算しない。同時到着は部隊ID順で開始家を決める。他家が来ても進捗を引き継げない。
- 制圧開始家の停止部隊がいなくなると毎日10ポイント低下し、0で記録を削除する。停戦・同盟化では制圧を終了する。
- 100%で郡と郡内の城・港を獲得する。城の独立攻略を要求する案4は採用していない。守備兵と出陣可能兵の旧家の残数を解消し、郡代・郡代任命台帳・農業/商業の担当を解除する。
- 領有確定時に既存の領主変更処理を通し、領域表示・奉行所の家紋と支配家の色・武将の配置を更新する。

## 統治の安定化

- 新規ゲームの既存領は安定度100%。制圧完了した郡は0%で始まり、獲得当日は安定化を進めない。再占領でも0%から再開する。
- 安定度が100%未満の間は金銭・兵糧収入を50%にし、徴兵・出陣と毎月の兵の回復を停止する。収入は既存どおり月次/九月の徴収時に計算し、日割り精算はしない。
- 毎日 `100 / 60 × (1 + 駐屯補正 + 郡代の政治 / 30)` ポイント回復する。駐屯補正は奉行所タイルに停止中の自家兵が合計100人以上なら1、それ以外は0。政治補正は0〜1の範囲。
- 郡代なし・無駐屯で60日、100人以上の駐屯で30日。政治30の郡代と駐屯を併用すると20日。大将の政治は郡代任命なしでは適用しない。
- 敵部隊が奉行所周辺にいる間は、100人以上の駐屯があれば回復停止、なければ毎日2ポイント悪化する。0〜100に収め、反乱・自動独立・自動返還は起こさない。
- 100%で通常収入と徴兵を再開する。兵数は次の月次回復や帰還で戻り、安定化完了時に新しい兵を一括生成しない。
- 駐屯中も腰兵糧を消費する。奉行所での自動補給は追加していない。CPUは制圧と安定化のために駐屯し、兵力不足・帰還用兵糧不足では撤退を優先する。

## 表示と保存

- 郡パネルと部隊パネルに制圧率、推定残り日数、敵接近・撤退による停止理由、統治安定度、収入/徴兵制限を表示する。
- 郡代は従来の値のボタンから任命する。新しいアイコンや別の変更欄は追加していない。
- 保存形式20で郡の安定度と制圧開始家・進捗を保存・検証・復元する。旧形式の移行は実装しない。
