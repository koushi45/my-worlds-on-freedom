# 九州旧国境界 v1.0.0 の本番組み込み

2026-09-09（JST）のユーザー指示「問題ないので、本番マップに組み込み＆windowsビルドをお願いします。」を承認として記録した。

- 承認正本: `data/master/political/kyushu/1.0.0/`
- 本番データ: `data/derived/political/approved_kyushu/`
- 表示: `scripts/map/political_boundary_layer.gd`
- Windows版: `builds/windows/MyWorldsOnFreedom.exe` と同じフォルダーの `.pck`
- 配布用ZIP: `builds/MyWorldsOnFreedom-Windows-Kyushu-v1.0.0.zip`

基盤ポリゴン・海岸線はハッシュ不変。作業用データはそのまま保全し、承認済みのスナップショットからのみ本番データを生成する。作業候補を再生成しても本番の採用内容は変わらない。

本番の全国マップを維持し、九州本島に15共有境界と正本海岸線を透明レイヤーで描画する。国名・選択線はクリックで表示。選択線は対象国の共有国境と海岸線参照から構成し、クリックポリゴンの外周は描かない。5段階の表示と既存タイルカリングを維持し、九州が画面外のとき政治境界レイヤーも非表示とする。

「九州へ移動」ボタンを追加。対象は9旧国のみで、離島の所属や他地方の政治境界は今回の承認対象に含めていない。

ゲーム内に帰属・変更内容を表示し、Windows配布物には帰属文・CC BY-SA 4.0本文・派生境界JSONを同梱した。未承認の作業画像・レビューシーン・政治境界QAはエクスポート対象から除外した。

## 確認済み

- 正本の不変性・地域数・共有境界参照
- 本番のクリック選択、5 LOD、画面外の政治レイヤー非表示
- 出力済みPCKからの地図・国境・国選択の読み込み
- 出力済みPCKに作業データ・レビュー画像がないこと
- Windows実行ファイルの起動、正常終了、エラーログなし
- 配布ZIPのCRC検査

ビルドのSHA-256とサイズは `builds/windows_build_report.json` に記録する。

通常の再生成は `python tools/publish_kyushu_political.py`。`--approve` は新しい明示承認を受けた場合のみ使用し、既存の承認版を上書きしない。
