# ゲーム内時間

- 開始日：1546年1月1日。信長の元服年は1546年（天文15年）。[名古屋市の解説](https://www.city.nagoya.jp/naka/miryoku/1021146/1033230/1049391.html)を参照。1月1日はゲーム上の開始日であり、元服当日の再現ではない。
- 地図の初期表示準備後に1倍速で開始。1秒につき1日、2倍は2日、4倍は4日、8倍は8日進む。
- 日付計算は西暦のグレゴリオ暦規則を過去へ適用。月ごとの日数・うるう年に対応。当時の旧暦換算は行わない。
- スペース：停止／再開。キーを押し続けた際のリピートは無視。
- キーボード上段の1・2・3・4：それぞれ1倍・2倍・4倍・8倍。
- 右上：年月日、減速、再生／停止、加速、現在速度。再生中は「停止」、停止中は「再生」。速度の上下限では該当ボタンを無効化。
- 停止中でも速度を選択可能。停止状態を維持し、表示した速度で再開する。途中まで進んだ1日の端数を保持。
- 時間倍率はゲームカレンダーだけに適用。地図操作・描画速度には影響しない。時計はOSの時刻変更に影響されない単調増加時間で進む。
- 起動ごとに開始日へ戻る。セーブ／ロードは未実装。

`scripts/game/game_clock.gd` は表示から独立した時計。日ごとの `day_advanced(year, month, day)` シグナルへ今後の内政・移動・戦闘等を接続できる。低フレームレートや8倍速でも経過した日を1日ずつ通知する。`scripts/game/time_hud.gd` が表示・ボタン・キーを担当する。
