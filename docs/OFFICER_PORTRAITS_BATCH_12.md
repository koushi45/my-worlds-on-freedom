# Officer portraits, batch 12

Ten modern strategy-game bust icons were created separately with the built-in ImageGen tool. Image 1 in each call was a web-searched source; Image 2 was the project's `assets/officers/portraits/oda_nobunaga.png` for rendering style only. The subject's facial shape, age, headwear, costume and gaze were instructed from Image 1, specifically the small central officer image in each banner, with banner UI and text excluded. Source images were not copied into the game.

No verified historical portrait of these ten officers was located in this search. Four exact-name *Nobunaga's Ambition: Shinsei* faces were found. For the remaining six, the indicated game face depicts a **different person** and was used only as an explicitly disclosed design proxy, not as a likeness claim. Ninomiya Naritoki has an older-series appearance recorded [here](https://famicom1252.blogspot.com/2015/12/2.html), but a usable exact-person face image was not verified for this production. Nihonmatsu Harukuni and Ieyasu may have ambiguous family/alias treatments in secondary compilations; the game's separate registry entries are retained separately here.
