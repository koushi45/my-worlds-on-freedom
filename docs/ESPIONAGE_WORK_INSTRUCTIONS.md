# 外交・諜報コマンド 調査と実装手順

作成日：2026-10-05。ゲームのコード変更前に作成した実装の基準書。

## 調査結果と出典

- [EU4公式開発日誌（2016-02-11）](https://store.steampowered.com/news/posts/?appids=236850&enddate=1455788577)：外交官が対象国ごとの諜報網を構築し、最大100の値を消費して即時に工作を成功させる。構築していない諜報網は減衰する。防諜は敵の諜報網を弱める。
- 同日誌には請求権捏造、交易紛争正当化、反乱支援、不満扇動、行政潜入、評判毀損、独立扇動、徴兵妨害、商人中傷が記載される。行政潜入は戦場の霧の解除、徴兵妨害は回復速度低下、商人中傷は交易力低下を目的とする。
- [EU4公式Wiki・Espionage](https://eu4.paradoxwikis.com/Espionage)は取得時401で閲覧できなかった。公式開発日誌の確認できた仕様を参考にする。日誌は過去の開発仕様であり、現行EU4の費用・解禁条件を確認したものではない。以下の数値は本ゲーム独自の調整値。
- 現在のゲームには外交使節・方向別友好度・30日の外交待機・宣戦時の威信減少・停戦・保存処理がある。諜報値、請求権、EU4型交易ノード、戦場の霧、従属国制度はない。治安、商業収入、出陣兵力の月次回復は存在する。

## 採用仕様

諜報値は家の共通通貨ではなく「自家→対象家」の諜報網（0〜100）とする。各家の外交官は通常3人。関係改善の使節と諜報網を構築する間者は共通枠を使い、1活動につき1人を占有する。複数家へ同時派遣できるが、合計3人に達すると新規派遣できない。対象家への帰還操作または関係改善完了で枠を解放する。即時外交・諜報値を消費する工作は継続派遣枠を占有しない。派遣中は月初+5、他の網は月初-2。費用不足・無効な対象で値を消費しない。同盟家への敵対工作は禁止し、防諜は許可する。費用を払えば確実に成功する。

| コマンド | 諜報消費 | 本ゲームでの効果 |
| --- | ---: | --- |
| 間者派遣／帰還 | 0 | 網の構築開始／停止。現在の派遣先を表示する操作ボタン |
| 請求権捏造 | 20 | 対象家が現在所有する郡をボタンから選択。1825日間の請求権。既存の有効な請求権への重複捏造不可 |
| 不満扇動 | 60 | 360日間、対象家の郡で月初の治安を3低下（下限0） |
| 評判毀損 | 50 | 360日間、第三者から対象家への有効友好度-20（下限-100）。基礎友好度は変えず期限後復帰 |
| 徴兵妨害 | 50 | 360日間、対象家の月次出陣兵力回復を20%低下（端数切捨て） |
| 商人中傷 | 70 | 360日間、対象家の商業収入を25%低下 |
| 防諜 | 30 | 対象家→自家の諜報値を30減らす。敵諜報網がなければ実行不可 |

持続工作は同種・同対象への効果中の再実行禁止。他家による同種工作も重複させない。工作には既存外交と同じ30日の対象別待機を適用し、派遣・帰還は除外する。請求権が対象家の現在所有郡にある場合、外交の宣戦は正当化され威信-30を免除する。所有者が変わった郡は旧所有者への正当化に使えず、請求郡を取得した家には使えない。宣戦で領有権そのものは移転しない。

本ゲームでは郡間隣接の専用外交判定がないため、捏造は対象家の全所有郡を候補とする。EU4の隣接制限・技術解禁・DLC条件は移植しない。交易紛争、行政潜入、独立扇動は対応制度がないため今回は採用しない。反乱支援は既存の家臣反乱と性質が異なるため、不満扇動に集約する。CPUは侵攻候補に間者を派遣し、諜報値20で郡の請求権を捏造する。有効な請求権がある相手だけに自発的に宣戦する。防衛参戦は従来どおり可能。

## 実装手順

1. `diplomacy.gd`に諜報網、派遣、請求権、持続工作と期限の状態・条件判定・費用消費・月次更新を追加。宣戦正当化を組み込む。
2. 外交画面に「諜報」を追加。諜報値と費用・効果・期間・実行不可理由を表示。請求郡は捏造ボタン押下後の選択ダイアログで指定。既存の漆黒・金のボタンを使用し、新規アイコンは追加しない。
3. 商業収入と兵力回復に有効な工作の倍率を接続。第三者友好度への期限付き補正を外交判定にも反映。
4. 保存形式を29へ更新し、諜報状態の保存・読み込み・検証を追加。旧形式移行は作らない。
5. 費用不足、消費、構築／減衰、重複、期限、領主変更、正当化、妨害実効値、保存と復元、UI選択をテストする。既存外交も確認。
6. Windowsリリース版を既存の書き出しツールでビルドし、成果物と起動を確認。結果を本書へ追記する。
