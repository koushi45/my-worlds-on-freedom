# Officer portraits, batch 28

Ten square alpha-transparent PNG Maeno portraits for the game. The images contain no labels or other text.

## Reference search and use

Individual image/web searches were made for all ten names with `肖像`, `顔グラ`, and `信長の野望` terms. No verified exact-person modern portrait was found for any of the ten. The search instead repeatedly returned different Maeno officers, chiefly [前野忠康](https://altema.jp/nobunagashinsei/busyo/1844) and [前野長康](https://altema.jp/nobunagashinsei/busyo/1845). Their actual cropped game portraits were supplied to image generation as **style/material references only**, explicitly forbidding reuse of their faces, helmets, or poses. None of the ten generated faces is presented as a historical likeness.

The roster's own biographical notes provided age/role differentiation. Some are based on tentative genealogy or `武功夜話`-related traditions, so those details are visual interpretation rather than verified personal appearance.
