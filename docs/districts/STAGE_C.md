## 全国の共有境界網

`network.json` の `boundaries` が編集正本。各郡候補は `boundary_refs` で同じ線を参照し、面の `polygon_geometry` は派生物とする。共有区間を両郡に別々に描く構造にしていない。境界ID、所有候補、資料ID、原座標、地図座標、不確実性を区間単位で保持する。

原資料の完全に一致する線分のみを共用し、接続点で区間を分けた。近い線の吸着、丸めによる接続、曲線の平滑化、細分化、現代の河道・海岸・国境への強制移動は実施していない。線分の切り方が異なる境界や交差の自動修復は含まない。検証結果はこの処理範囲に限る。

同じ国の線を修正するときは一つの `boundaries` を編集し、変更理由・参照箇所を付けた別版を保存する。面を個別に移動してつじつまを合わせない。元の比較案を再生成するコマンドは作業ファイルを上書きするため、手編集版は別ディレクトリに置く。今後の編集UIと変更版の再構成機能は別工程。

親領域とのずれ・未被覆面積も台帳に残した。現行親領域での切断、穴埋め、飛地の採用、全国の被覆保証は工程D以降。現段階の線を、そのままゲームの国の下位区画として採用しない。

## 和泉国：元禄図の補正案

[原図と読取り位置](../../data/work/districts/stage_c/izumi/genroku/source_annotations.png)／[補正画像](../../data/work/districts/stage_c/izumi/genroku/registered.png)／[比較画像](../../data/work/districts/stage_c/izumi/genroku/comparison.png)／[対応点・変換行列・残差](../../data/editorial/districts/stage_c/izumi_registration.json)／[対応点の根拠資料](../../data/editorial/districts/stage_c/registration_sources.json)

資料：国立公文書館「元禄国絵図和泉国」、請求番号 特083－0001-0010、画像識別子 `C100189194000 / 010_izumi.jp2`。元禄期の比較資料であり、1582年の直接証拠ではない。画像台帳に1696年相当のメタデータと写本年代未確認を分けて記録した。[原資料のIIIF情報](https://www.digital.archives.go.jp/api/iiif/764247/manifest.json)

寺社・城の記号の代表点を暫定比定し、既存基準地図へ単一のアフィン変換で合わせた。原図の記号が現代施設の測量点に等しいとは仮定していない。

|対応点|原画像ピクセル|当てはめ残差|
|---|---|---:|
|大鳥大明神 → 大鳥大社|330, 680|1,703m|
|槇尾山 → 施福寺（暫定）|866, 890|1,589m|
|岸和田城|303, 1290|2,560m|
|久米田寺|502, 1195|795m|
|水間寺|721, 1580|1,652m|

当てはめRMSEは **1,752m**、1点ずつ外した照合のRMSEは **6,152m**。独立した検証点は0点で、後者も独立検証ではない。暫定作業基準（当てはめ500m、1点除外1,000m）を超えたため `held_registration_accuracy_insufficient` とした。この基準は史料の精度規格ではない。

対応点は北部から中央に偏り、特に日根郡南部は外挿が未検証。信太明神は比定の混同のおそれがあり除外した。海岸・河口を基準点にせず、残差を小さくするためのスプライン変形や局所的な引き伸ばしをしていない。

原図で読める大鳥―和泉、和泉―南、南―日根の3本を、少数の観測頂点で暫定トレースした。[共有トレース網](../../data/work/districts/stage_c/izumi/genroku/shared_trace_network.json)には原画像ピクセルと補正後座標を併記し、4郡が同じ3境界を参照する。外周は未トレースで、閉じた面は `null`。補正精度が不足する線を後世ベクトルへ自動統合していない。

## 幅と不確実性

後世ベクトルの歴史的位置精度は不明値 `null`。表示用半幅2ワールド単位は単なる表示規約であり、誤差推定値ではない。和泉の原図は観察上の線幅2〜5ピクセル、手動トレース半幅4ピクセルを別々に記録した。補正図の帯は読取り幅と全体残差に基づく確認用表示で、統計的な信頼区間ではない。

年代差による境界の移動量は未確定のまま注記する。元禄図の色分け・幅広い線から一本の確定境界が得られたとは扱わない。400%で拡大できるSVGにも、新たな屈曲や補間頂点は足していない。

## 検証と再実行

Python環境に numpy、shapely、pyproj、Pillow が必要。

```powershell
python -X utf8 tools/build_district_stage_c.py fetch
python -X utf8 tools/build_district_stage_c.py build
python -X utf8 tools/register_izumi_district_map.py
python -X utf8 tools/review_district_stage_c.py
python -X utf8 tools/verify_district_stage_c.py
python -X utf8 tools/prepare_district_ledgers.py check
```

和泉の補正スクリプトは保存済み原画像を入力にする。再取得する場合は画像台帳の各URLを用い、元の保存物とハッシュを維持して別版に保存する。取得応答が変わった場合、元のピクセル対応点をそのまま流用しない。

検証対象：原資料ハッシュ、66親領域の網羅、同一原線分の二重保持、共有参照の整合性、面の妥当性と共有網からの復元、対応点残差の再計算。投影の数値往復誤差と史料の実測残差は区別した。工程A・Bの525入力ファイルの固定も確認した。比較画像の目視では、原図と現行地図のずれ・点群の偏りが表示されることを確認した。

## 残件

1. 和泉の対応点の比定と原図の図式化を再検討し、南部を含む独立した照合点を増やす。強い変形で帳尻を合わせない。
2. 摂津・河内・大和を含む他国の古地図を、原図と対応点の根拠が追える形で追加する。現在ある全国形状は後世ベクトルの比較案。
3. 追加10候補の位置、後世の分郡を戻す根拠、1582年への継続性を村郷などの所属資料で確認する。
4. 工程D以降で親領域内の面、飛地、未確定範囲、採否、画面機能を扱う。
