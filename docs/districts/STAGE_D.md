# 工程D：現行国の内部で区画を閉じる

作成日：2026-09-12。座標系は既存の8192×8192を維持。

**全66親領域で、工程Cの比較候補を現行国の内部に閉じた。共有辺から面・線・隣接関係を再生成し、資料のない部分は未確定領域として保持した。** 後世資料の候補を閉じる工程であり、1582年の史実として採用した結果ではない。

件数はレコード数。同じ候補や同じ未確定理由に属する離れた面は、一つのMultiPolygonにまとめる場合があり、連続した面の個数ではない。隣接件数は未確定領域との接触も含む。

入力は工程Cの697件。対象年に除外された9件は郡の採用候補へ昇格させず、重なる現行国の内部を未確定として保持した。親領域内に面が残らない候補も差分台帳に記録する。工程Bの位置未確定10候補には、新たな架空の形を割り当てていない。和泉の精度不足の元禄図トレースも閉区画の入力には採用していない。

## クリップと差分の保存

外周は `political_registry.json` の現行親領域を使用し、その国境・海岸に相当する既存外周を再利用した。外部資料の国形状、別の基準海岸、郡候補に合わせて親国を移動していない。

全候補の境界と親領域の外周を一度に交差処理し、できた面のうち親領域の内部を採用する。個々の候補を別々にクリップして交点を丸める方式を避け、T字接続や交差を同じ計算結果に統一した。これは交点の計算であり、近くの線を引き寄せる吸着処理ではない。

各国の `differences.json` に保存するもの：

- `parent_minus_source`：現行国に含まれ、資料の候補群では覆われない差分面。
- `source_minus_parent`：資料にはあるが現行国の外に位置する差分面。
- `candidate_clips`：候補ごとの外部切除面、残存面積、元資料参照・ハッシュ、処理理由。
- `pending_regions`：判断が必要な未確定領域への参照。
- `numeric_policy`：数値許容値、吸着・微小面削除を行わない方針。

処理理由は「変更しない現行親領域で候補をクリップする」。歴史上の境界を移動すべきと判断した記録にはしていない。大きな差もそのまま差分面に残る。

## 重なり・隙間・数値誤差

分割した面を原候補への所属で分類する。候補が一つなら比較郡候補、候補がなければ `source_gap`、複数なら `source_overlap`、対象年に除外済みの候補だけなら `excluded_at_target` として未確定にする。資料の不足を隣の郡の拡張で埋めない。今回の実データでは隙間と対象年除外による未確定領域が生じた。重複する資料を投入した場合の未確定化はテストでも検証した。

座標のグリッド丸め、近接吸着、微小面の削除、無条件の不正形状修復は行っていない。微小な面でも削除しないため、歴史判断との混同がない。面積 `1e-6` ワールド単位²、外周距離 `1e-8` ワールド単位は、浮動小数点の演算差を検証する許容値に限って使用する。境界を動かす量ではない。許容値を超えた場合は生成を失敗させ、値を上げて大きな差を消す処理にはしない。

## 編集正本・派生物・隣接

各国の `partition.json` に以下を保存する。

|項目|意味|
|---|---|
|`boundaries`|共有境界の編集正本。辺ID、両側の区画、原資料網参照、現行外周／内部共有辺、不確実性|
|`regions`|共有辺参照とそこから復元した閉じた面。候補・未確定理由・元候補IDを保持|
|`adjacency`|同じ辺網から生成した隣接関係と共有長・辺参照。点接触には接点座標|
|`parent_geometry`|比較と検証のための変更しない親領域|
|`candidates`|工程Cの入力候補の控え。内部の元形状はクリップ済み面ではなく出典確認用|

面を個別に直して隣とのずれを作らない。共有辺を正本として編集し、面と隣接を再生成する。今回の生成スクリプトは工程Cから工程Dを再生成するため、手編集版を保存する場合は出力先を分ける。編集UIは本工程で追加していない。

隣接は `shared_boundary`（共有長0.01ワールド単位以上）、`short_boundary`（0より大きく0.01未満）、`point_contact`（共有長0で接点あり）を区別した。0.01は調査上の分類基準であり、通行可能性や歴史的な隣接の確定を意味しない。短い辺を点へ置き換えず、長さを保存して後から閾値を変えられる。距離が近いだけの区画は隣接としない。

## 検証

全66親領域で次を確認した。

- 親領域の被覆、外部へのはみ出し、区画同士の面積重複。
- 外周と現行親領域境界の一致。
- 共有線分の二重保持がないこと、区画と辺の参照整合性、共有辺からの面復元。
- 出力された各面の境界を独立に交差計算し、共有長・点接触と隣接台帳が一致すること。
- 保存した差分面が入力資料と親領域の差と一致すること。
- 入力のハッシュ67件（親領域と工程Cの66網）、工程A・Bで固定した525ファイルの保持。

最大の未被覆面積は約4.1×10⁻¹¹、はみ出し約5.0×10⁻¹¹、重複約2.4×10⁻¹⁰ワールド単位²。外周の最大ずれは約9.1×10⁻¹³ワールド単位で、すべて演算差の許容値内。

合成データでは重なり・隙間、親領域の穴、点接触、短い共有辺、対象年除外、T字接続を確認した。和泉の画像で、未確定部分と外側に切り取った差分が区別して読めることも目視確認した。
