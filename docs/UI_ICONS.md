# UIアイコン

異なるラベルや意味に同じアイコンを使わない。技術・役職・能力・HUD・評定タブ・郡一括管理タブ・郡情報・施設・操作の91種類に、個別に生成した和風の専用絵柄を割り当てる。同じ意味の情報を別画面に表示する場合は同じ専用アイコンを使用する。

生成には組み込みの `image_gen` を使用。各アイコンのラベル、絵柄の指定、生成プロンプトは `assets/ui/unique_icons/manifest.json` に記録する。PNGの制作元は `assets/ui/unique_icons/sources/`、上部HUD・評定用の完成画像は `assets/ui/hud/compact/`、郡画面用の完成画像は `assets/ui/district/` に保存する。

漆黒・金・朱・生成りを基調とし、文字や外枠を画像に焼き込まない。制作時に256・192・128・96・64pxの5サイズを作り、実行時は画面の物理ピクセル倍率に応じて完成PNGを選ぶ。コンパクト表示では既存のセル寸法に合わせて透過余白を持たせる。

制作時のサイズ展開:

```powershell
python tools/build_unique_ui_icons.py <アイコンID> <生成PNGのパス>
```

全ラベルのPNG寸法・透過・デコード後の画像重複を確認:

```powershell
python tools/verify_unique_ui_icons.py
```

技術アイコンは技術IDごとの明示的な割り当てとし、別の技術や分類アイコンへのフォールバックを使用しない。新しい技術・ラベルを追加するときは、専用アイコンも追加する。
