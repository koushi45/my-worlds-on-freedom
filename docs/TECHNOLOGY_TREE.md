# 技術ツリーと郡の治安

各郡の基礎治安は開始時50/100。画面の郡詳細には、家が研究した技術の補正を加えた治安を表示する。分国法は研究時に支配中の郡の**基礎治安**を5上げる。兵農分離と大名介入は、支配家が持つ技術による治安補正としてそれぞれ+15、+10を加える。

統治技術・農業技術・商業技術は、それぞれ前段階を研究してから次へ進む。各技術は1回だけ研究でき、いずれも統治技術力1,000を消費する。城下町制度の研究が完了した後は、以後の費用が950となる。研究済みの技術は家ごとに保存する。

統治技術力の月次増加量は大名の政治、家老任命時は指定済みの合算式を使う。

## 商業技術

上から順に研究する。数値はゲーム用の調整値。

| 技術 | 効果 |
| --- | --- |
| 市場整備 | 市場の建築費 -15% |
| 商人保護 | 金銭収入 +5% |
| 度量衡整備 | 担当武将による商業開発の月次進行 +15% |
| 職人誘致 | 工房の建築費 -15%、建築期間 -2か月 |
| 問屋整備 | 市場の金銭収入補正を +10% から +20% へ強化 |
| 貨幣流通促進 | 金銭収入 +5% |
| 商工業振興 | 商業開発の月次進行をさらに +15%（累計 +30%） |
| 商業奉行設置 | 金銭収入 +10% |

商業の全体金銭補正は累計 +20%。統治の楽市と加算して +25%。問屋整備は市場の施設補正に加算し、施設補正と家の技術補正は乗算して最後に一度だけ収入を丸める。市場の建設プレビューと完成後の収入は同じ計算を使う。

開発加速は担当武将の政治による月次進行に適用する。通常時は無担当の郡は進行しない。集中管理命令中は、大名の政治能力によって担当未配置の分野も進行する。開発上限30は維持する。市場・工房の費用割引は基本費用に掛けて四捨五入（市場100→85、工房150→128）。工房は15→13か月となり、月途中の着工は既存の月初完成規則に従う。

費用・期間は着工時に確定し、研究によって進行中の工事は変わらない。現在のセーブ形式は25で、工事に着工時の期間 `months` を保存して完成日を検証する。取消時は支払い済み額を返す。市場の収入、着工前の費用・期間、開発加速は現在の支配家の研究に追従する。CPUは兵糧不足時に農業、金銭不足時に商業を優先し、その他の場合も商業を研究候補に含める。

## 効果の反映

- 兵糧・金銭の割合補正は加算してから各郡の収入計算へ適用する。全3系統研究後の家の補正は、兵糧+130%、金銭-10%。
- 人口台帳は研究した時点で、その家が支配する郡の人口を一度だけ10%増やす。
- 官僚機構制定と武家諸法度は、配下武将の表示忠誠にそれぞれ+5、+20を加える。
- 治安は0～100に収める。分国法の基礎値は郡に保存し、他の技術補正は現在の支配家から算出する。
- 農業施設建築費は用水路・農園の着工費に接続する。人口増加率、常備兵、渇水・洪水・台風被害は、それぞれの補正関数を使用する。


## 技術習得以外の命令

郡一括管理の「技術力命令」で左側の郡を選び、右側に並ぶ全6命令のボタンを押すと即時実行する。各命令に費用・効果・実行できない理由を表示する。担当武将は不要。費用は1郡単位。1郡に同時に1命令だけ実行できる。開始時に全費用を支払い、終了・中断時の返金はない。城下町制度による技術力消費5%減を適用する。

| 命令 | 技術力 | 金銭 | 兵糧 | 準備・効果 |
| --- | --- | --- | --- | --- |
| 新領地の統治整備 | 統治120 | 60 | 0 | 90日間、統治安定化の正の進行速度+50%。敵部隊による停止・悪化は既存どおり |
| 郡の巡察 | 統治60 | 20 | 0 | 30日準備後、90日間治安+15。重税補正は継続し、期限後に巡察補正だけ消える |
| 開発事業の集中管理 | 統治120 | 80 | 0 | 90日間、農業・商業の月次開発進行+50%。担当未配置の分野は大名の政治能力で進行。上限30を維持 |
| 災害復旧の指揮 | 統治90 | 60 | 100 | 90日間、3日ごとに荒廃度-2（最大60）。荒廃による農業・商業の収入低下が段階的に回復 |
| 国衆・在地勢力との折衝 | 外交120 | 100 | 0 | 30日準備後、統治安定度+20・自治度-20を一度適用。以後180日間は税率30%以下を約束 |
| 防衛準備 | 軍事100 | 80 | 100 | 30日準備後、90日間攻城戦の防御係数+25%・奉行所の制圧進行÷1.25。自家の郡内城・奉行所だけに適用、野戦無効 |
| 出陣前の調練 | 軍事100 | 0 | 兵数×0.1（切り上げ） | 部隊画面から実行。帰郡先で14日準備後、90日間、接近戦・弓・攻城の戦闘効率+15% |

郡の技術力命令は武将を拘束しない。命令中も出陣・郡代変更が可能で、担当武将の選択・派遣・解除は行わない。領主変更時は命令を中断する。準備と効果の残り日数を表示する。

折衝の安堵は既存の自治度と減税によって表現する。約束発効後の任意中止は不可。期限後は元の税率へ戻すが、約束中にプレイヤーがさらに減税した場合はその税率を維持する。

防衛は郡の未出陣兵と自家の郡内城の守備兵の合計100人以上が必要で、守備兵不足中には防衛効果を適用しない。資材費は金銭に含む。調練中は移動・帰郡・合流・自動命令を制限し、敵軍が帰郡先へ接近して接近戦または奉行所駐留となった場合は調練を中断する。通常の腰兵糧消費も継続する。

調練済み部隊と未調練部隊の合流時は、調練済み兵数の割合で効果を薄める。調練済み部隊同士の合流では早い方の期限を引き継ぎ、合流による期限延長はしない。

荒廃は災害・略奪に共通する現在の被害指標を使用する。施設ごとの破損状態や国衆ごとの人物・交渉シミュレーションは現行のゲーム状態にはない。巡察は実際の治安値へ接続し、独立した騒乱抽選は追加しない。

セーブ形式30に、命令対象・支配家・準備期限・効果期限・復旧進行・折衝の元税率と、部隊の調練状態を保存する。旧形式の移行は追加しない。

検証：7命令の費用・条件・準備・期限・実効果、現行形式のファイル保存／読込、未調練兵との合流による効果低下を自動確認。既存の郡管理・出陣・占領・合流・日付進行・セッション確認も通過。GPU画面とWindows出力PCKで追加命令を確認し、Windowsリリース実行ファイルで35日分の進行と保存・再開を確認（失敗0件）。
