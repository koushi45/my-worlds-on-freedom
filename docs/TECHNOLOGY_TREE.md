# 技術ツリーと郡の治安

各郡の基礎治安は開始時50/100。画面の郡詳細には、家が研究した技術の補正を加えた治安を表示する。分国法は研究時に支配中の郡の**基礎治安**を5上げる。兵農分離と大名介入は、支配家が持つ技術による治安補正としてそれぞれ+15、+10を加える。

統治技術と農業技術は、それぞれ前段階を研究してから次へ進む。統治技術は「分国法 → 官僚機構制定 → 人口台帳」の順。各技術は1回だけ研究でき、どちらのツリーも統治技術力1,000を消費する。城下町制度の研究が完了した後は、以後の費用が950となる。商業技術ツリーも表示するが、研究項目は未設定。研究済みの技術は家ごとに保存する。

統治技術力の月次増加量は大名の政治、家老任命時は指定済みの合算式を使う。旧セーブに残る農業技術力は読み込み時に統治技術力へ合算する。

## 効果の反映

- 兵糧・金銭の割合補正は加算してから各郡の収入計算へ適用する。全研究後の最終補正は、兵糧+130%、金銭-30%。
- 人口台帳は研究した時点で、その家が支配する郡の人口を一度だけ10%増やす。
- 官僚機構制定と武家諸法度は、配下武将の表示忠誠にそれぞれ+5、+20を加える。
- 治安は0～100に収める。分国法の基礎値は郡に保存し、他の技術補正は現在の支配家から算出する。
- 人口増加率、常備兵、農業施設建築費、渇水・洪水・台風被害には補正計算を用意した。現在のゲームには人口の定期成長、常備兵、建築、災害の実行処理がないため、これらの効果は対応する処理が追加されたときに使用される。
