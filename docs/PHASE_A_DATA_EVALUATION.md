## 結論

第一候補は **国土交通省「国土数値情報 行政区域データ N03-20260101」** とする。海岸の細かさ、離島収録、原本の位相検査結果はいずれも、Natural Earthよりゲームの正本に適している。

ただし、配布ページには原典として国土地理院の測量成果を使用した旨と、二次利用時に国土地理院への申請等が必要な場合がある旨が明記されている。このため、現時点の判断は **条件付き採用推奨** であり、商用同梱を確定する前に国土地理院へ利用形態を提示し、測量法上の申請要否について書面回答または必要な承認を得ることを必須ゲートとする。

Natural Earthは権利処理が最も容易だが、1:10,000,000の汎用地図用データであり、湾岸・瀬戸内海・九州西岸・南西諸島の細部が不足する。正本にもLODにも混在させず、比較参照に限定する。

### 必要な修正方針

1. 市区町村ポリゴンは歴史境界には使わず、全域を結合して現代海岸の候補外周だけを得る。
2. 原本をJGD2011の適切な平面直角座標系へ分区変換してから固定精度化し、行政境界を消去する。
3. 海と湖を接続性・水域資料で分類し、湖の穴を誤って陸化しない。
4. 離島を自動削除しない。ゲーム収録範囲・最小面積は別の承認項目として決める。
5. 結合後に自己交差、穴、重複、極小片、往復線、海岸の切断を再検査する。
6. 正本確定後は、全LOD、クリック判定、海岸線、地形マスクを同じ正本から生成する。

## 同一条件での比較

全画像は候補ごとに同じ中心、物理範囲、JGD2011平面直角座標系、画像寸法で描画した。Natural EarthはLandだけでなく公式Minor Islandsも重ねている。色は識別用で、海岸修正・平滑化・簡略化・結合は行っていない。

| 確認地点 | 比較結果 |
|---|---|
| 北海道 | 大形状は双方で一致。N03は根室周辺・小島・湾曲が細かい |
| 東京湾 | N03は埋立地、港湾形状、細い水路が明瞭。Natural Earthは大幅に一般化 |
| 伊勢湾 | N03は湾奥・志摩半島・島嶼が詳細。Natural Earthは狭い入り江を省略 |
| 大阪湾 | N03は湾岸改変・島・海峡が詳細。Natural Earthはゲーム狭域用途には粗い |
| 瀬戸内海 | 差が最大。N03は多数の島と水道を保持し、Natural Earthは相当数を省略・単純化 |
| 九州西岸 | N03は長崎・天草・湾岸の複雑さを保持。Natural Earthは細部が大幅に減る |
| 南西諸島 | 小島レイヤー追加後も、N03の方が島数と輪郭密度が高い |
