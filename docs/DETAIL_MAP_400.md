# 400%表示と拡大用地図

地図座標・基準陸地・道路探索用DEM・立体表示の変換は従来の8192×8192のまま。変更はズーム制御と描画専用データ。

## ズームと読込

通常のホイール操作は1.3倍刻み。下限は `MIN_ZOOM = 0.5`（50%）、初期表示も50%、上限は `MAX_ZOOM = 4.0`（400%）で、拠点へ移動・路線選択でも共用する。ホイール操作はカーソル下の地表位置を保つ。画面サイズ変更でも拡大率を維持する。50～200%では国境、200%を超えると郡境を表示する。

100%未満は既存の5段階LOD画像を使用。100%以上は陸地のある256×256座標単位の小タイルに切り替える。211タイルのうち、画面範囲と立体投影の余白に交差するものだけを保持し、画面外のノードと画像参照を解放する。全国分の画像を一括でGPUへ載せない。

## 高解像度の色・陰影

描画専用にAWS Terrain Tiles / Mapzen Terrariumのzoom 11を取得し、元の投影へ変換。各タイルは1座標単位あたり4画素、内部1024×1024、四辺4画素の余白を含め1032×1032。400%の平面表示では内部の画像1画素が画面上の約1画素になる。

従来の色画像を引き伸ばさず、細かい標高値から同じ配色・照明方向で陰影を再計算した。画素の間隔は約57mだが、元DEMの実質的な地形精度は地域や原典によって異なり、測量精度を意味しない。日本の範囲で4500m超などの不自然な原データ値は描画用コピー上だけで3×3中央値に補正し、manifestに元値と置換値を記録する。

全画像は同じグローバル座標からサンプリングする。余白に隣のタイルと同じ画素を含め、線形補間と陰影計算による継ぎ目を防ぐ。

## 陸地と海岸線

既存の承認済み陸地ポリゴンを、立体表示で使っている16座標単位の三角形に沿って切り分ける。陸地・島・穴を維持し、元の三角形面に一致するメッシュへ色画像を貼る。陸海の境界にラスターのアルファマスクを使用しない。

海岸線は元の陸地ポリゴンの境界だけを取り出し、立体表示の三角形に沿って細分してから、アンチエイリアス付きの線として描く。タイルを切った端を海岸として描かない。見た目の輪郭を高精細にする変更であり、元のNatural Earthの概略海岸線に未収録の入り江などを創作しない。

道路・国境・水域・拠点・文字の独立した描画を維持する。道路の座標、接続関係、拠点の位置、クリック判定の地表変換は変更しない。

## 再生成と検証

`python tools/build_detail_map.py` で描画専用データを生成。入力・元タイルのハッシュ、座標系、補正記録を `data/derived/detail_map/manifest.json` に保存する。元タイルのキャッシュは `data/sources/elevation/terrarium/11/`。従来の道路用 `elevation_m.png` や表示変位用 `mesh_height.png` を上書きしない。

`test_detail_map.py` は陸地面積・ポリゴン一致・立体三角形への一致・海岸線・隣接画像の余白・入力ハッシュを検査する。Godotの `test_detail_zoom.gd` は通常操作・拠点・路線選択の上限、画面内だけの読込、切替・パン・400%の平面／立体描画を確認する。

出典・帰属は既存の [標高データ帰属](../data/derived/elevation/attribution.md) を継承。提供元：[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)。

## 実測確認

全国211タイルの形状・継ぎ目・入力検査3件、Godotの400%操作・描画テスト、既存の地形投影・道路接続テストに合格。地形PNGの合計は約132MB。全量を常駐させず、実画面の読込対象と保持タイルの一致を確認した。
