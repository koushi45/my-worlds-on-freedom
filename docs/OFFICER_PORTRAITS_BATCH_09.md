# Officer portraits, batch 09

Ten original bust icons were generated individually with built-in ImageGen. Each generation used a web-searched person-specific source image as **Image 1**, with `assets/officers/portraits/oda_nobunaga.png` only as **Image 2** for the game's modern painterly finish. Only the small central face was used from Altema banners; their lettering, interface and backgrounds were explicitly excluded. Source images are not shipped with the game.

The two Nakagawa portraits are historical *depictions*, not claims of a verifiable lifetime likeness. Searches did not establish historical portraits or exact named Nobunaga's Ambition portraits for the other eight officers. Their references are explicitly **different game officers used as design fallbacks**, not representations of the requested people.

Prompt pattern: `Create an original modern Sengoku strategy-game officer bust. Image 1 is the primary source; preserve its row-specific face, age, hair, costume palette, expression and gaze. If Image 1 is a game banner, use only its central face image and ignore the interface. Image 2 defines painting finish only, not face or pose. Keep head, neck and shoulders anatomically aligned. Crop above hands to prevent malformed fingers. Output a single square transparent-alpha PNG with no background, text, frame or UI.` Each row also had the individual anchors above explicitly specified. All generated images are new interpretations, not copies of source works.
