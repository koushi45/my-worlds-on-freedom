# 武将の忠誠（1546年開始設定）

全1598人の初期値は `data/derived/officers/loyalty_1546.json` に収録。初期忠誠は全員40、初期必要忠誠は原則35。資料から後年の行動が確認できる7人のみゲーム用の例外値とした。必要忠誠は開始時最大70、プレイ中最大90。忠誠は0～100。

## プレイ中の計算

表示忠誠 = 本人の忠誠 + 階級補正 + 俸禄差補正 + 統治任命補正 + 威信補正。結果は0～100に収める。

- 侍大将：忠誠+5、基礎俸禄の5倍。軍師・家老・所司代：忠誠+10、基礎俸禄の20倍。
- 基礎俸禄が要求額を0.1上回るごとに+5、0.1下回るごとに-10。初期の基礎俸禄と要求額はともに0.1/月。
- 郡代：忠誠+5。国代：忠誠+10。両方ある場合は国代の+10のみ。侍大将以上だけ任命できる。
- 家の威信が50から離れると、差の30%を整数に丸めた補正を全配下に付ける。50以外では最低1の補正、範囲は-15～+15。
- 毎年1月1日に、出仕中の家臣の本人の忠誠と必要忠誠をそれぞれ+1。勤続5年ごとに要求基礎俸禄と実際の基礎俸禄を同時に0.1/月増やす。
- 毎月1日、表示忠誠が必要忠誠を**下回る**家臣の離反を判定する。郡代・国代なら担当領地で独立し、それ以外は別家へ出奔する。別家の選択は威信の高い家を優先する。戦闘処理から `on_battle_defection` に部隊データを渡せば、武将と部隊の所属を同時に変更できる。現時点のゲームには部隊・戦闘システムがない。

過去のセーブは初期値を補い、セーブ日時までの勤続年数を反映する。新形式は武将の忠誠・要求額・俸禄・統治任命・独立勢力を保存する。
