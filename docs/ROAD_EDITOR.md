# 開発者モード・道編集

ゲーム中の「メニュー → 開発者モード」から操作パネルを開く。

## 標準の道と未接続の奉行所

標準の道は `data/derived/scenarios/hex_roads_1546.json`。2026-09-28に再受領した `hex_roads.json` を内容そのままで採用した。7414タイル・接続除外447辺。SHA-256は `f0d7e9efd7849cdf839af1008ec60038ee953e2e6c6f7cf045479724a3b15a09`。前回の四国・九州の道の削除後に、受領ファイルでは両島の道も追加されたため、今回の正式データには含まれる。通常ゲームでも起動時から読み込む。表示は六角形と同じく200%以上。

開発者モードでは、奉行所タイルから隣接する道タイルへの有効な接続が1本もない郡を、不透明度20%の薄赤で塗る。奉行所タイルに道がない場合、孤立した点だけの場合、すべての接続を削除した場合が対象。別の奉行所まで到達可能かどうかの判定ではない。
道編集のON/OFFや拡大率によらず表示し、追加・削除・接続変更・元に戻す・読み込みで更新する。開発者モード終了時に赤塗りを消す。通常地図・等高線図どちらでも有効。

## 地図表示の切り替え

「地図：通常」を押すと「地図：等高線（50m）」に切り替わる。もう一度押すと通常表示に戻る。
等高線図では通常の地形画像を非表示にし、元の標高データから50m間隔の線を描く。250mごとの線は濃い太線で示す。
表示用の起伏強調や平滑化メッシュではなく、`elevation_m.png` のメートル値を使う。50mは標高の間隔であり、元のDEMの水平解像度を高めるものではない。
海には海底等深線を描かない。地図は真上からの表示に固定し、六角形・道・河川・郡境などは同じ座標に重ねる。
道編集と併用可能。通常表示に戻すか開発者モードを終了すると、以前の斜め表示設定と背景を復元する。
この表示設定は開発者モード内のみ有効で、ゲームのセーブには保存しない。

生成：`python tools/build_contour_height_field.py`。元の16bit標高をRGB画像のR/Gへ可逆格納し、Bには陸域マスクを格納する。
描画時は各サンプルをメートル値へ復元してから補間し、256mの境目で偽の等高線が発生しないようにする。
検証：`godot_console --path . --script tests/base_map/godot/test_contour_mode.gd`。

## 道の編集

「道編集：OFF」を押すと編集を開始し、200%未満なら200%へ拡大する。
編集中はゲーム時間を止める。奉行所は家紋と支配大名家の背景色で表示したままにする。奉行所タイルをクリックした場合も、道の追加・削除を行う。

- 六角形を左クリックすると道の有無を切り替える。既存の道も削除できる。
- 道がある隣接6方向のタイルは、中心同士を自動で結ぶ。既存の道を編集に取り込んだ際も同じ規則を適用する。
- 「編集対象：タイル」を押すと「編集対象：接続線」へ切り替わる。線の中央付近をクリックすると、その接続だけを削除する。両端の道タイルや他の接続は残るため、三角形の一辺だけを消せる。
- 削除した接続は接続線の編集中だけ赤い破線で示し、クリックで復元できる。通常表示では破線は表示しない。接続の削除・復元も「元に戻す」「やり直す」に対応する。
- 接続先のない道タイルは中心の点で表示する。道タイルの背景を薄く着色して示す。
- 左／中ボタンドラッグで地図移動、ホイールで拡大縮小。ドラッグは道の編集として扱わない。
- 200%未満や六角形の描画範囲外では編集しない。海岸線からの既存の六角形表示範囲にも従う。
- 「元に戻す」「やり直す」で直近のクリック操作を戻せる（最大2000操作）。
- 「道データをエクスポート」で任意の場所にJSONを書き出す。
- 「道データを読み込む」でそのJSONを再編集する。読み込みは現在の道全体を置き換え、操作履歴を消去する。不正なファイルの場合は編集中の道を保持する。
- 「道編集：ON」または「開発者モードを終了」で通常操作へ戻る。編集した道の表示は現在のマップに残る。

編集データはゲームのセーブとは別管理。タイトルに戻る・ゲーム終了の前にエクスポートする。編集操作は標準の道データを直接上書きしない。再起動後は標準の道から始まり、編集中のJSONを読み込むと作業を再開できる。
編集対象はマップの道路表示であり、軍の移動コストやシナリオの拠点接続台帳は変更しない。

## エクスポート形式

```json
{
  "schema_version": 1,
  "kind": "hex_road_network",
  "hex_radius": 6.0,
  "coordinates": "pointy_top_axial_q_r",
  "connection_rule": "all_six_occupied_neighbors",
  "cells": [[100, 100], [101, 100]],
  "excluded_edges": [[[100, 100], [101, 100]]]
}
```

`cells` は道が存在する全タイルの軸座標 `[q, r]`。差分ではなく全体を保存する。
`excluded_edges` は自動接続から除外する辺の両端座標。省略時は除外なし。除外はタイルを削除・再追加しても維持し、エクスポート・読み込みにも含める。
中心座標は `x = √3 × radius × (q + r/2)`、`y = 1.5 × radius × r`。
隣接差分は `(1,0), (0,1), (-1,1), (-1,0), (0,-1), (1,-1)`。
両端のタイルが存在するときだけ辺を作り、片端を削除すると接続も削除する。
六角形サイズ・座標系・接続規則の不一致、重複座標、小数の座標、描画範囲外の座標は読み込みを拒否する。

検証：`godot_console --path . --script tests/base_map/godot/test_road_editor.gd`
