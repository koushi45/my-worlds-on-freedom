# 部隊の合流と武将編集

自家部隊を選択し、同じ六角形にもう1部隊を停止させると「合流」ボタンが有効になる。相手の部隊を選んで「合流」を押すと1部隊にまとめ、直後に大将・副将の編集画面を開く。接近戦中、移動中、他家の部隊、別の六角形の部隊は合流できない。

## 合流後の編成

合流前の2部隊の大将・副将から、統率が最高の武将を大将に選ぶ。残る候補のうち武勇の高い2名を副将にする。同点は武将ID順で決定する。兵数は合計、腰兵糧の日数は兵数による加重平均とし、端数も保持する。軍馬・鉄砲は実際の残数を合算し、装備のない兵まで装備済みとして扱わない。

選択していた部隊のID・帰還先を引き継ぎ、合流相手を削除する。双方の旧移動・自動操作命令は解除する。部隊の向きは選択部隊を引き継ぎ、弓の再装填待ち時間は長い方を引き継ぐ。奉行所の制圧率は郡に保存されるため、合流で失われない。

## プレイヤーによる編集

合流直後の編集画面で大将1名・副将0〜2名を変更できる。既に役職にある武将を別の枠で選ぶと、その2名の役職を入れ替える。編集は即時反映し、統率を使う制圧・攻城と、役職者の平均武勇を使う野戦の評価に反映する。

全参加武将は随伴武将として部隊内に保持する。役職のない武将も編集候補に残るが、現在の戦力計算に加えない。随伴中は別部隊へ出陣したり郡配置を変更したりできず、帰還すると全員が再び出陣可能になる。後から部隊パネルの大将・副将の値を押して再編集できる。

## 保存と確認

現在の保存形式23で、役職者・全随伴武将・小数を含む腰兵糧・軍馬/鉄砲の実数を保存する。旧形式の移行は行わない。
