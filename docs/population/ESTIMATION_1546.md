# 1546年郡人口の推定方法

## 結論

本データは、史料と明示した仮定に基づく**1546年のゲーム用推定人口**であり、史実の確定人口ではない。現行の有効653郡すべてに初期値を設定した。地図内の採用ケース合計は11,108,276人、低位ケースは9,050,987人、高位ケースは16,744,326人である。

全郡を暫定採用とした。1546年前後の郡別人口を全国一律に揃えられる史料は確認できず、現版の郡内配分は後代の村落分布を用いるためである。

## 全国総量

国立社会保障・人口問題研究所『人口統計資料集 2026』表1-6は、鬼頭宏『人口から読む日本の歴史』による1600年人口を12,273,000人とする。これを採用ケースの1600年総量とした。

比較ケースには、Angus Maddison, *The World Economy: A Millennial Perspective*, Appendix B の整理を用いた。同書はHayamiの1600年推計を1,000万～1,400万人、Maddisonの採用値を1,850万人とし、1500～1600年に年0.18%の増加率を仮定している。低位を1,000万人、高位を1,850万人とし、3ケースとも次式で1546年へ戻した。

```text
P1546 = P1600 / (1 + 0.0018)^54
```

この率は全国総量の年代補正だけに使用した。各国・各郡に同率の人口増加を仮定したものではない。年代補正後の全国値は低位9,074,538人、採用11,137,180人、高位16,787,895人である。ここから後述する地図外3国相当分を配分代理量の比率で控除した。推定幅は整合的な代替ケースの幅であり、統計的信頼区間ではない。

## 国別配分

1598年『日本国総目録【日本國六拾余州御検地御蔵納金銀納高目録】』の国別石高構成比を、生産規模の代理指標として全国総量の配分に用いた。石高を人口へ1石=1人で換算していない。

後世に分割された陸奥5国と出羽2国は、それぞれ1598年の陸奥・出羽の総量に戻してから郡へ配分した。現行ゲーム境界が包含する志摩は伊勢、若狭は越前へ合算した。壱岐・対馬には1598年表の石高がないため、0人口を避ける低確度の代理量として2万石相当・2.5万石相当を仮定した。ただし壱岐は現行郡形状に村落点が対応せず、地図外として総量から除外した。

## 郡内配分と境界対応

本田謙一・夏目宗幸・根元裕樹「幕末期近世村領域データ」v2.01の66,581村落代表点を、WGS84からプロジェクト所定のLCC投影・ゲーム座標へ変換し、現行の独立郡形状へ空間集計した。

- ポリゴン内に入った点：65,409件
- 海岸線等の差を考慮し50ゲーム単位以内の最近傍へ対応：558件
- 地図外または対応距離超過：614件
- 有効郡へ対応した合計：65,967件

佐渡262件、隠岐61件、壱岐22件は現行郡形状に対応しなかったため、各国の人口を本土地図へ配り切っていない。対馬は有効な独立郡だが村落点が海岸形状差により対応せず、測地面積補完となった。その他の未対応点は海岸線差、島の収録範囲、復元点とゲーム境界の差による。

郡内重みは原則として村落点件数である。0件だった1郡だけは、同じ配分群の「村落点件数÷測地面積」をその郡の測地面積へ掛けて補完した。測地面積はゲーム描画面積ではなく、形状をWGS84へ逆変換しGRS80相当の測地計算で求めた。

この村落分布は幕末期の資料であり、1546年の人口・村数ではない。新田開発、都市化、村の成立・消滅、境界変化を完全には補正できないため、村落点で配分した652郡を確度C、面積補完1郡を確度Dとした。都市人口は分離不能なので総人口の内訳として扱い、別枠加算していない。

## 丸めと再現

全国総量を国別代理量へ、次に各配分群を郡別重みへ配り、各段階で最大剰余法を使用する。同率は郡ID順で確定する。このため整数化後も全ケースの全国合計と各配分群合計が保存される。

編集用正本は `data/work/population/`、生成物は `data/derived/population/` に置く。次のコマンドで同一入力から再生成・検証できる。

```powershell
python tools/build_district_population.py
python tools/verify_district_population.py
```

村落点の再取込が必要な場合だけ、引用元v2.01のCSVを指定して次を実行する。

```powershell
python tools/import_population_village_counts.py --village-csv <01_Village_point_data_v2.csv>
```

## 制約と改善候補

郡別の検地帳、戸数、人口記録を追加し、`direct_adjusted` または `household_based` へ置換することが最大の改善点である。とくに京都・堺等の都市、山間、島嶼、戦乱影響地域は後代村落数だけでは捉えにくい。国別石高にも検地精度の地域差がある。次版では試行地域ごとの直接資料、都市内訳、地域別年代補正を追加し、全国総量だけに依存しない検証を行う。
