# 三好姓10名の肖像・正式採用記録

2026-09-30。組み込みimagegenで1名ずつ制作した、写実的な西洋油彩の胸像。西洋風にするのは技法のみで、日本人の人物像と日本の衣服を描く。史料は顔・髪・髭と衣装だけに使用し、姿勢や背景、伝統絵画の身体比率は引き継がない。全10枚は1254×1254pxのRGBA透過PNG（アルファ0〜255）、文字・フレームなし。生成結果を個別に目視し、頭・肩の比率、髪・帽子の収まり、衣装と顔を確認。

ゲームへの正式採用先は `scripts/game/officer_portraits.gd`。完成PNGと同名の `.prompt.txt` を `assets/officers/portraits/` に保存。人物ID・採用パス・能力値・プロンプト全文・参照画像名は `portraits_adopted_20260930_batch3.json`。生成元はCodexのgenerated_imagesに保持した。

## 採用史料

### 三好実休

[京都大学貴重資料デジタルアーカイブ「三好之虎像（模本）」RB00033861](https://rmda.kulib.kyoto-u.ac.jp/item/rb00033861)。所蔵：京都大学総合博物館。紙本著色、江戸中期。原本自体も伝写本と解説される後世の肖像。記録は之虎を義賢・之康・元康とも称し、法名実休と同定している。賛文の永禄5年を、現存模本が制作された年とは扱わない。

IIIF画像を `references/miyoshi_jikkyu_kyoto.jpg` に保存し、実見して生成ツールへ渡した。剃髪、丸みのある顔、細い目・眉、髭のない顔、白い襟と赤い内襟、灰色の上衣を参照。顔の向きと胸像の構成は変更し、座像の肩幅や胴体比率を写していない。

[堺市博物館展示一覧](https://www.city.sakai.lg.jp/kanko/hakubutsukan/exhibition/kikaku_tokubetsu/kako/74549120220902185140834.files/tenzihin.pdf) と[藍住町「藍住歴史かるた」解説書・PDF26ページ](https://www.town.aizumi.lg.jp/docs/2013112900029/file_contents/1837_pdf2.pdf) でも妙國寺所蔵の別の実休像を確認した。こちらの写真は小さく、衣装が異なるため今回の生成衣装と混ぜていない。抽出写真 `references/miyoshi_jikkyu_reference.png` は補助確認用として保持。

**三好之虎（実休）と今回の三好長虎は別の登録人物。之虎像を長虎の参照に使っていない。**

### 三好義興

[京都大学「三好義興像（模本）」RB00033862](https://rmda.kulib.kyoto-u.ac.jp/item/rb00033862)。所蔵：京都大学総合博物館。江戸期の模本。[徳島城博物館の展示一覧](https://www.city.tokushima.tokushima.jp/johaku/tokubetsutenji/R05_tokubetsu.files/R05_list02.pdf) では江戸中期、原本は永禄6年（1563）とされる。京都大学の解説では知恩寺養源院にあった五軸の一つであろうかとされ、伝来の推定を確定扱いしない。

IIIF画像を `references/miyoshi_yoshioki_kyoto.jpg` に保存・実見し、生成ツールに渡した。若い髭のない面長の顔、細い眉と目、黒い烏帽子、淡青色の花柄の衣服、赤と黄の襟を参照。花柄は資料の衣装を基準とし、座像・扇・背景・文字は採用しない。

### 三好長慶

[早稲田大学図書館「三好長慶像」ワ03 03645 0390](https://www.wul.waseda.ac.jp/kotenseki/html/wa03/wa03_03645_0390/index.html)。彩色の写本、書写年不明。「宗点拝謄」とある。所蔵機関の説明では原本は京都市聚光院所蔵、賛は永禄9年7月4日。[文化庁国指定文化財等データベース](https://kunishitei.bunka.go.jp/heritage/detail/201/1348) も聚光院本を1566年、重要文化財と記録している。賛の年を今回用いた写本の制作年とは扱わない。

早稲田公開PDFから画像を抽出し、色形式をRGBへ変換して `references/miyoshi_nagayoshi_waseda_0.png` に保存。実見し生成ツールへ渡した。丸みのある成熟した顔、細い口髭と頬・顎の髭、黒い烏帽子、淡い青灰色の衣装と白い桐文、赤・淡緑・白の花柄の襟を参照。資料内の衣装文様のみを使用し、根拠のない家紋や甲冑を追加しない。頭・肩の比率を人体に合わせ、顔の向き、姿勢、光は新たに構成した。

大東市公開の『飯盛城「御体塚」を掘る』も資料探索に使用したが、そのPDFの図版は採用画像にしていない。大東市の近年の銅像・CGは史実の外見の根拠に使わない。

全3名とも、模本を使った顔・衣装の再構成であり、本人の容貌の確定的復元ではない。参照画像はゲームのWindows書き出しから除外される。
