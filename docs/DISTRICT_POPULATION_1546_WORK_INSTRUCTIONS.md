# 各郡の史実に基づく推定人口設定：作業手順書

作成日：2026-09-22  
状態：実施手順。人口値の調査・登録・ゲーム実装は未実施。  
対象：1546年開始シナリオの有効な全郡区画。

## 1. 目的と採用方針

各郡に、歴史資料と説明可能な推定に基づく初期人口を設定する。目標は、全郡について「なぜこの規模なのか」を追跡でき、地域差に一定の歴史的妥当性があるゲーム用の人口台帳を完成させることである。史料にない精密な人口を確定値として扱わない。

- 基準年はゲーム開始年の**1546年**とする。開始日は1546年1月1日だが、人口は年単位の推定であり、その日の実測値とはしない。
- 人口は男女・子供・高齢者を含む地域の総居住人口とする。農村・都市・港・寺社・武家の住民も含め、兵力・成人男性・納税者数とは区別する。
- 全有効郡へ代表値を設定し、下限・上限・推定方法・出典・根拠の強さを併記する。資料不足の郡は推定方法を切り替え、無断で0人や全国一律値にしない。
- 数値は「史料の記載値」「年代・範囲を補正した値」「ゲーム用採用値」に分ける。ゲームバランスのための変更は独立した補正欄に残す。
- 今回の工程は初期人口までとする。人口増減、徴兵、税収、食糧消費は別工程で設計する。

既存の拠点手順書にある「人口・石高は未設定」という方針に対し、本工程では郡人口の推定を明示的に導入する。拠点人口は、郡内の内訳として必要な場合に限り推定する。

## 4. 工程B：史料を集める

### 調査順序

1. 人口史の研究から、16世紀の全国・地方別人口について推定法と対象地域の異なる説を比較する。引用先の同じ数値を独立した証拠として数えない。
2. 旧国別に自治体史・地域史・史料集・検地関連研究を探し、人口・戸数・村数・耕地・石高の記載を収集する。
3. 郡・村・都市単位の資料へ進み、記録年、数えた人の範囲、地理的範囲、欠落を確認する。
4. 1546年付近の資料がない場合は近接時期の資料へ広げ、後世の資料を使うほど年代差の説明を厚くする。
5. 調査入口・候補資料・本文確認済み資料を区別する。入手できない本文の数値を推測して引用しない。

### 資料の優先順位

| 優先度 | 資料 | 用途と留意点 |
|---|---|---|
| 1 | 対象時期・対象範囲に近い人口記録、原史料を検討した地域人口研究 | 記録対象の偏りを確認して直接推定の基礎にする |
| 2 | 戸数・家数、検地帳、耕地・生産規模、集落調査 | 人口への換算仮定を明示する。「家」が居住世帯か確認する |
| 3 | 後代の地域別人口・石高・村数と地域史 | 地域差の補助指標。年代差・新田開発・都市化・郡再編を検討する |
| 4 | 地形、居住可能地、周辺の比較可能な地域 | 資料不足郡の補完。地形だけから史実の人口が分かるとはしない |

石高を「1石＝1人」と一律換算しない。軍勢数も、そのまま総人口へ換算しない。近代・現代の人口分布、現在の農地、登録済み拠点の件数だけを中世人口の分布として使わない。

## 5. 工程C：史料地域を現行区画に対応付ける

1. 「史料地域ID → 現行郡ID」の対応を作る。同名郡でも旧国・年代・範囲を確認する。
2. 合併済みの郡は、重複のない元地域人口を合算する。既存の合計値とその内訳を両方加算しない。
3. 分割された地域は、村の所属・集落分布・耕地等を優先して配分する。面積比しか使えない場合は最下位の補完とし、その理由を記す。
4. 国境をまたぐ区画は、旧国ごとの部分人口を計算してから現行郡IDに合算する。表示上の親領域へ全人口を押し込まない。
5. 島と本土の人口を別計上する場合、元地域の総人口から島分を取り分ける。追加区画への複製はしない。
6. 境界が重複・未確定なら、人口配分用に一意の帰属または重みを定義する。表示形状の重なりをそのまま二重計上しない。

対応表には `source_region_id`、`district_id`、`allocation_weight`、`basis`、`source_ids`、`boundary_confidence` を持たせる。単一原地域からの配分比率は地図外分を含めて1にする。異なる年代・資料の同一地域は代替観測であり、配分元として足し合わせない。

地理面積は適切な投影法または測地面積で算出する。現在の `map_area` は描画座標上の面積なので、そのままkm²や人口密度へ使わない。

**完了条件：** 全有効郡に対応情報があり、配分元の重複と配分先の漏れがない。

## 6. 工程D：1546年の総量と人口配分を決める

### D1. 全国・地方・旧国の総量

1. 採用する研究の年代・地域範囲を揃え、全国または地方の代表値と代替値を記録する。本手順書では全国人口の具体値を先決めしない。
2. 地域別研究が使える部分はそれを優先し、残りを共通のモデルで補う。細かい資料がない地域を無理に精密化しない。
3. 全国値は整合性の目安とし、直接資料と衝突した場合は範囲・年代・集計対象を再確認する。単に全郡へ同じ倍率を掛けて合わせない。
4. 全国値から地図外分を控除する場合は、その推定根拠も残す。地域ごとの範囲が揃わなければ、全国との比較は参考値として扱う。

後年 `t` の人口から遡及する場合は、例えば `P1546 = Pt / (1 + r)^(t - 1546)` とする。ただし `r` は研究・地域資料に基づく仮定であり、全地域共通の固定成長率を無根拠に設定しない。根拠が弱い場合は増加率を変えた複数ケースを残す。年代補正ができない後代の数値は、直接人口ではなく配分の補助指標に下げる。

### D2. 郡ごとの推定方法

| 方法コード | 条件 | 処理 |
|---|---|---|
| `direct_adjusted` | 近接時期の人口記録がある | 対象人口・年代・地域範囲を補正 |
| `household_based` | 居住世帯数が使える | 世帯数×平均世帯人数。世帯人数の出典・幅を記録 |
| `regional_allocation` | 郡の直接値はないが地域総量と分布指標がある | 地域の残余人口を比較可能な重みで配分 |
| `analogue_fallback` | 地域分布資料も乏しい | 地形・生業等が近い資料のある地域を参照し、低確度で補完 |

根拠の強い方法から選び、方法の異なる結果を無条件に平均しない。資料不足の全郡も最後の方法で暫定代表値を持たせ、根拠が改善した際に置き換えられるようにする。

### D3. 残余人口の配分式

旧国等の配分単位 `p` について、次を定義する。

- `T_p`：採用総人口。
- `F_p`：郡全体の人口を別途採用した区域。その人口合計を `D_p` とする。
- `U_p`：それ以外の未配分区域。
- `C_i`：未配分区域内で別途確保する都市等の人口。根拠がなければ別枠にせず0とする。
- `W_i`：都市別枠を除いた人口を配るための非負の重み。

```text
R_p = T_p - D_p - Σ(C_i),                       i ∈ U_p
P_i = C_i + R_p × W_i / Σ(W_j),                 i,j ∈ U_p
```

`R_p < 0`、未配分区域があるのに `ΣW_j = 0`、未配分区域がないのに残余がある場合は計算を停止し、総量・範囲・重複を見直す。直接採用区域内の都市は既に含まれるため追加しない。

重みは同じ配分単位内で比較できる指標に統一する。まず対象時期に近い村別戸数・生産規模等の単一指標で成立するか確認し、不足する場合のみ複合指標へ進む。複合指標の候補は次の形とする。

```text
W_i = a × K_i / ΣK + b × H_i / ΣH + c × A_i / ΣA
a + b + c = 1,  a,b,c >= 0
```

`K` は比較条件を揃えた生産規模、`H` は重複しない農村世帯等、`A` は居住・耕作可能地の面積。利用可能な指標だけを採用し、係数は資料のある地域との比較で決めて版管理する。どの係数も史実の定数とはしない。

- 欠測は0と区別する。一部郡だけ指標が欠ける場合は、同じ単位で補完して明記するか、配分単位全体で共通の指標へ切り替える。
- 戸数・石高・面積には関連があるため、同じ人口集積を重ねて強調していないか比較する。
- 都市・港・寺社人口を別枠にするときは、配分指標も可能な限り農村分に限定する。分離できない場合は都市人口を内訳扱いにし、別枠加算しない。
- 「有名な城がある」だけでは人口を増やさない。1546年には未成立の城下や後年の城下拡張も反映しない。
- 戦乱・飢饉・移転等は対象時期と影響地域の根拠がある場合に限り考慮する。減少率の根拠がなければ数値を創作せず代替ケースで扱う。

### D4. 下限・代表値・上限

総人口、世帯人数、年代補正、配分係数、境界対応を変えた整合的な複数ケースを計算する。各郡の最小値・採用ケースの値・最大値を保存し、これは**シナリオに基づく推定幅であり統計的信頼区間ではない**と明記する。

全国一律の「±20%」等を根拠なく付けない。入力が共有する不確実性もあるため、郡別の最小値をすべて足した数を全国下限とはしない。全国・旧国の幅はケースごとの合計から求める。

代表値はゲーム内部では整数にする。丸め前の値を保存し、配分単位内は最大剰余法などで合計を維持する。同率の場合は郡ID順で確定する。表示は資料の精度に合わせ「約1.2万人」等とし、整数保存を1人単位の史実精度と誤認させない。

**完了条件：** 全郡に代表値と推定幅があり、元の総量・仮定から再計算できる。

## 7. 台帳の必須項目

| 項目 | 内容 |
|---|---|
| `district_id`, `name`, `scenario_year` | 有効ID、名称、1546 |
| `population_estimate`, `population_low`, `population_high` | 人単位の非負整数、下限≦代表値≦上限 |
| `population_definition` | 総居住人口。原史料の定義との差は観測台帳へ記録 |
| `method`, `adoption_status` | 推定方法、`adopted` または `provisional` |
| `evidence_grade` | A：時期・範囲が近い人口資料、B：戸数等から補正、C：地域総量配分、D：類似地域・地形で補完 |
| `temporal_confidence`, `boundary_confidence` | 年代・境界それぞれの確かさと理由 |
| `source_ids`, `observation_ids`, `assumption_ids` | 原資料、観測値、仮定への参照 |
| `allocation_group_ids`, `crosswalk_ids` | 総量の配分単位と範囲対応への参照 |
| `urban_population_included` | 都市分の包含・別枠の扱い。分離不能も明記 |
| `notes`, `review_status` | 資料不足、例外理由、確認状況 |
| `model_version`, `boundary_version` | 計算方式と境界の版 |

Aでも史実の確定人口とは限らない。世帯人数や年代補正に強い仮定がある場合は評価を下げる。資料不足は `provisional` として採用できるが、出典やモデルの参照が空のまま採用しない。直接史料がない郡は、補完に使用した地域資料と仮定を参照させる。

## 8. 工程E：試行と全国展開

1. 先に山城、尾張、信濃、対馬を候補として試行する。都市集中・平野・山地・島を含むことが目的であり、資料状況に応じて比較可能な地域へ変更できる。
2. 各試行地域で、史料収集→範囲対応→総量→配分→感度分析→検証を一巡させる。
3. 直接資料のある郡の一部を検証用に残し、推定結果との差を確認する。モデル調整に使った同じ値だけで精度を主張しない。
4. 過大評価・過小評価の原因を確認し、共通規則を確定する。例外的な手修正を大量に作らない。
5. 地方単位で全国へ展開し、地方ごとに検証報告を残す。資料不足の地域は補完方法で全件を埋める。
6. 境界版・計算方式・採用総量を凍結して全国版を生成する。

**完了条件：** 全有効IDが採用済みまたは暫定採用で一度ずつ収録され、未調査のまま放置された郡がない。

## 9. 工程F：ゲームへ反映する

1. 人口台帳をIDで読み込む独立した処理を追加する。統治台帳の島追加・有効郡絞り込みが終わった後に結合する。分割元の人口を島へ複製しない。
2. 新規開始時に各郡へ代表値を設定する。読込時に件数とID集合を検証し、欠落・重複・負数はエラーにする。
3. 調査用の初期値とゲーム中の現在値を分離する。推定幅は研究上の情報であり、毎回ランダムな人口を引くためには使わない。
4. 人口を可変状態として持たせる場合、`game_session.gd` の保存・検証・復元へ加え、保存形式の版を更新する。台帳版も記録する。
5. 人口項目のない旧セーブは採用初期値から補完し、移行したことを記録する。既に人口のあるセーブはその値を維持し、台帳更新で上書きしない。旧IDの合併・分割は対応表で総数を保存して移行する。
6. 画面に表示する場合は「推定人口」「1546年初期値」を識別できるようにする。現在の画面には統治情報パネルがないため、調査確認だけを目的に旧パネルを復活させず、開発用表示や派生一覧を利用する。
7. 配布対象へ人口JSONを含め、実際のエクスポート環境で読込を確認する。

既存のフェーズG用 `population.gpkg` と連携する場合は、今回の台帳から別の派生処理として生成する。人口という総数属性は、ポリゴンを切り出しただけでは正しく配分されない。分割前後の総量保存を検証する。

## 10. 工程G：検証と完了判定

### 自動検証

- 有効郡ID集合と人口ID集合が完全一致し、重複・欠落・廃止IDがない。
- 値が有限の非負整数で、下限≦代表値≦上限。0人には個別の根拠がある。
- 全出典・観測・仮定・対応表への参照が解決する。
- 配分比率が地図外を含め1で、合併・分割・都市内訳の二重計上がない。
- 各計算ケースで配分単位の総量が保存され、丸め後も代表値合計が目標と一致する。
- 同じ入力とモデル版から同じ出力を生成できる。
- 生成後に境界ハッシュが変わっていない。

### 人による確認

- 上位・下位の人口、陸地面積当たり人口密度、類似地域から外れる値を一覧と地図で確認する。
- 都市周辺、山間部、島、国境横断区画、合併区画を重点的に確認する。高密度・低密度を理由なしに一律修正しない。
- 全国・地方・旧国の合計を、採用に使わなかった比較可能な研究とも照合する。差があれば対象年・範囲・方法の違いを報告する。
- 仮定を変えると人口や順位が大きく動く郡を列挙し、推定幅と確度へ反映する。
- 確度別の件数と人口比率を示し、暫定補完が占める割合を見えるようにする。
