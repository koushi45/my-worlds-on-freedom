# 未評価から選定した100人・生涯能力評価（第17組）

総合能力は5項目の単純合計で最大150。各能力は1〜30点、1点刻み。統率・武勇・知略・政治・人望の全500項目を評価。数値は生涯の実績を参考にしたゲーム用の暫定判断であり、史料に記された測定値ではありません。
既存名簿1620人の未評価140人から100人を選定。新規登録は行わず、旧1480人の評価を保持。掲載順は知名度を目安にした編集判断であり統計順位ではない。実在・同定保留の人物や資料不足項目には暫定値を置き、その理由を個別に記載。1546年の存命確定・年代保留や幼少の判定は能力評価と別です。家臣の所属・所在・出仕は未設定です。
統率＝大軍の運用、武勇＝直属部隊の戦術成果、知略＝外交・戦略、政治＝統治・政策、人望＝部下の定着と登用人材の活用。
新基準：成否の材料なしは12前後、参照範囲で失敗のみの項目は5前後。任務参加が確認でき目立つ失策が伝わらない場合は標準遂行と解釈し、戦域・規模・責任に応じ14〜24点。成果・失敗の記録があれば個別に加減する。参加から標準遂行への推定はユーザー指定のゲーム上の解釈。既存の評価は再査定していない。

## 各項目の評価理由

「暫定推定」は特に資料の限られる項目。それ以外も史実を手掛かりにした編集評価です。出典は人物ごとの参照事項を支えますが、個々の点数や全ての理由を保証しません。

### 富樫泰高

加賀守護をめぐる抗争、半国分治、一向一揆後の再擁立を評価する。晩年の実権には制約があった。1504年以前の死去とされ、1546年の出仕対象を意味しない。

- 統率 24：在地勢力を組織して守護職を争ったが支配は分裂。（功績・失敗を比較）
- 武勇 22：加賀の長期抗争への参戦を地域主力の標準遂行とする。（参加実績から標準遂行と解釈）
- 知略 23：幕府有力者との連携で復帰した一方、一揆側の制約を受けた。（功績・失敗を比較）
- 政治 23：半国分治と守護職の運営を担うが全域支配は安定しなかった。（功績・失敗を比較）
