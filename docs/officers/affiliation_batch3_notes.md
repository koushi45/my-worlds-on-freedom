# 1546年・配置未登録者の追加100人（第3組）

配置未登録の人物から前2組と重複しない100人を選び、全員に5種類の立場のいずれかと現行の配置郡を設定した。所属家あり23人、所属不明77人。立場の内訳は元服前64人・浪人23人・武将9人・大名2人・大名家一門2人。

出自、本拠、親族の居所、後年の活動圏を人物ごとに確認した。幼少期の場所が分からず後年の地域を借りる場合は、ゲーム上の代替配置と明記している。配置が1546年の実居住や領有を証明するものではない。生没年・人物同定の保留は維持し、元服前と年代未確定の人物は出仕無効とした。

## 父の所属の引き継ぎ

元服前かつ所属不明の場合、既存の父子台帳または人物紹介に記された父を人物表と個別照合する。父が登録され所属家が設定済みの場合だけ引き継ぐ。父が未登録・所属不明・同定未確定の場合は不明のまま。姓の一致、兄の所属、母方祖父、後年の主君だけでは引き継がない。

該当8人：多功綱継、大井行吉、島津忠康、植村家存、池田知正、中条景資、国分盛廉、柿並幸慶。池田知正は今回同時に設定した父・長正から引き継ぐ。父の設定を先に確定してから照合するため、一覧の順番に左右されない。

大井行吉の父の武田出仕を1551年とする紹介、島津忠康の日向での庇護の記事などは、登録済み父のゲーム所属と異なる。父の既存設定は今回変更せず、引き継ぎはユーザー指定の家族所属ルールとして保存する。千秋季忠・渡辺長は本人の幼少期の家督・奉公記事による所属判断で、父未登録からの自動引き継ぎではない。

## 選定・資料の留保

現行地図に配置可能な人物を選び、若狭・志摩・対馬・蝦夷など配置郡がない家の既存人物は変更しない。調査中、1460年に活動した一色政煕と、父が1537年生とされる下間頼亮は1546年の配置対象として適切な根拠がなく候補から除き、仁木友梅・三浦貞盛に差し替えた。除外を含む選定履歴は基準台帳に保存する。

主に既存の人物紹介の保存版を個別に再読。保存版のなかった小梁川盛宗（戦国時代）・内藤源左衛門の紹介を追加取得した。小梁川は室町期の同名人物の記述を使わず、内藤は紹介の人物同定・規模に疑問があるため場所のみ代替配置に用いた。半田市報は中山勝時の岩滑の地縁の補足資料とする。全100人を一次史料で確定した調査ではない。

## 再生成と保護

- 入力：`tools/officers/affiliation_batch3_selection.json`、`affiliation_batch3_decisions.txt`
- 生成処理：`tools/officers/apply_affiliation_batch3.py`
- 変更前1598人：`data/master/officers/affiliation_batch3_baseline.json`
- 変更前後・個別判断・出典URL・保存版ハッシュ：`data/master/officers/affiliation_batch3_research.json`
- 表示：`docs/officers/affiliation_research_third_100.html`

```powershell
python tools/officers/build_affiliations.py
python tools/officers/build_roster.py
python -m unittest discover -s tests/officers
python tools/officers/check_html.py
godot_console --headless --path . --script tools/officers/smoke.gd
```

第2組の後に第3組を独立した追加処理として適用。既存1498人、能力値、家系、父母子台帳を保持する。五井松平家・能見松平家は別々の家中として追加し、既存家の郡プールは拡張しない。配置は同家で人数の少ない郡から固定シードで選び、再生成で移動しない。

ユーザーが許可した所属変更の検証基準として、`lineages_baseline.json` の所属ハッシュだけを更新した。旧値・新値は `affiliation_batch3_migration.json` に保存し、能力ハッシュ・人物IDの基準は変えていない。第2組のテストは第三組の明示的追加100人を認識させ、第三組の独立テストで変更対象が厳密に100人であることを検証する。

差し戻す場合は `apply_affiliation_scenario.py` の第3組呼び出しを外して再生成し、所属ハッシュを移行記録の旧値へ戻す。第3組のリンク・報告書・専用テストも併せて取り下げる。前2組の元判断データは編集不要。
