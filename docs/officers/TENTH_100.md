# 追加の著名武将100人・生涯能力評価（第10組）

総合能力は5項目の単純合計で最大150。各能力は1〜30点、1点刻み。統率・武勇・知略・政治・人望の全500項目を評価。数値は生涯の実績を参考にしたゲーム用の暫定判断であり、史料に記された測定値ではありません。
既存1,360人の未評価者から知名度を目安に100人を追加選定。掲載順は今回100人内の編集判断であり統計順位ではありません。既存780人の評価を保持。1546年の存命確定・年代保留や幼少の判定は能力評価と別です。家臣の所属・所在・出仕は未設定です。
統率＝大軍の運用、武勇＝直属部隊の戦術成果、知略＝外交・戦略、政治＝統治・政策、人望＝部下の定着と登用人材の活用。
新基準：成否の材料なしは12前後、参照範囲で失敗のみの項目は5前後。任務参加が確認でき目立つ失策が伝わらない場合は標準遂行と解釈し、戦域・規模・責任に応じ14〜24点。成果・失敗の記録があれば個別に加減する。参加から標準遂行への推定はユーザー指定のゲーム上の解釈。既存の評価は再査定していない。

## 各項目の評価理由

「暫定推定」は特に資料の限られる項目。それ以外も史実を手掛かりにした編集評価です。出典は人物ごとの参照事項を支えますが、個々の点数や全ての理由を保証しません。

### 母里小兵衛

黒田家譜と家臣伝で戦死時期が異なる点を留保。黒田方での戦闘参加に限定し、武兵衛や友信の武功は移さない。

- 統率 18：黒田方の地域部隊として合戦に参加（参加実績から標準遂行と解釈）
- 武勇 18：討死のみを個人的な指揮失敗としない（参加実績から標準遂行と解釈）
- 知略 12：遺族を託す逸話を外交成果としない（成否材料なし）
- 政治 12：具体的な領域政務の担当は未確認（成否材料なし）
- 人望 12：職隆への信頼と直属配下の支持は別（成否材料なし）

生涯の業績からのゲーム用比較値。参加が確認でき目立つ失策がない任務は標準遂行と解釈。成否材料なし・失敗のみは今回の参照範囲の判断であり、史料の完全な網羅を意味しない。未誕生者の評価は開始時の出仕を意味しない。
