# 生涯能力の平均15点方針

2026年9月30日、登録済み1,598人の5能力を `historical_mean15_v3` へ更新した。総合値は5能力の合計。史料の多寡を能力の優劣に置き換えず、資料不足・参加からの推定・功績と失敗・重大失態の判定を区別する。

## 調査入力とゲーム用評価

`data/master/officers/assessments.json` は旧尺度で収集した史料要約・項目別の根拠・評価順を保持する調査入力。旧点数をそのまま現在のゲーム能力には用いない。

`python -X utf8 tools/officers/build_roster.py` がその入力に `score_policy_mean15.json` と `major_failure_reviews.json` を適用し、ゲーム台帳・人物詳細・組別資料を再生成する。二重適用は拒否する。生成済み台帳を入力にして再度減点する処理や旧セーブの移行処理はない。

現在の点数は `data/derived/officers/officers_1546.json` の `assessment.scores` と `total_ability`。CSV出力もこの台帳から作る。元の根拠・旧点数・評価区分・補完条件は各項目の `score_provenance` に保存する。

## 史実の成果の扱い

旧評価は任務への参加だけで20点前後になっていたため、単に「記録なし」の点数を変更しても全体平均を15にはできなかった。全員を同じ基準で評価し直す。成果が確認できる項目は、政策ファイルの単調な対応尺度に従って再評価し、分布を整える目的の乱数を付けない。旧評価の相対的な強弱と、卓越した実績を残す。

- 標準遂行：14〜16点前後。
- 明確な成果：17〜21点。
- 顕著な成果：22〜26点。
- 卓越した成果：27〜30点。
- 成功と失敗が混在する場合：既存の比較根拠を共通尺度へ換算する。
- 参照範囲で失敗のみ：項目別の低評価を維持する。それだけでは全能力低下を発動しない。

この更新は既存の史料要約と項目別評価を用いた尺度の再評価であり、1,598人全員の原史料を新たに精査したことを意味しない。追加史料や責任・挽回の確認に応じて、調査入力と個別レビューを更新できる。

## 記録なし・参加実績の補完

成否材料なしは中心15・標準偏差3の切断正規分布（整数6〜24点）から補完する。関連する能力に功績・比較根拠がある場合に限り、その根拠を保存して中心を最大±1点補正する。統率と武勇、知略と政治の間で弱い補正を使い、人望は他能力から推測しない。家柄・知名度・開始時の身分や病気を補正に使わない。この関連補正もゲーム上の仮定である。

参加実績は成果の確認と区別する。旧資料の責任・任務規模の評価を使い、中心11〜16点、標準偏差1.5、整数10〜18点の範囲で遂行を推定する。小規模・補助的な任務と標準的・広域的な責任を区別する。参加という事実から成功を捏造しない。

補完の固定シードは方針ID・人物ID・能力項目からSHA-256で得る。順序変更や再生成で個人差は変わらず、別の能力にも同じ乱数を使わない。範囲外を単純に端点へ押し込む処理を避け、端点への集中を防ぐ。

各能力の平均を15へ近づけるため、記録なし・参加からの推定の中心に共通の校正を加える。幅は±2点以内。功績・失敗に基づく確定したゲーム点数や重大失態の低評価は校正対象外。整数化による僅かな誤差は許容する。目標範囲は14.5〜15.5。

補完値のばらつきは史実で実証された個人差ではない。人物詳細で「成否材料なし・ゲーム用補完」「参加実績から遂行を推定」と表示し、平均値・中央値・12点の割合は `ability_distribution.json` に保存する。

## 重大な失態と挽回

本人の判断・行動に重大な責任があり、その後の挽回が認められない場合は、ご指定のゲームルールとして全能力を3〜9点に制限する。以前の功績は資料から消さず、低評価の理由を別に記す。敗戦・落城・改易だけ、史料が少ないこと、主君への不興、病気、家族の失態だけでは発動しない。

今回の個別適用は生駒高俊・徳川忠長・京極高広・大友義統・原田宗輔・稲葉通重の6人。責任と挽回の判断・出典・留保は `major_failure_reviews.json` に保存する。稲葉通重は既存人物伝の再確認に基づく暫定判定で、原史料の追加照合を要する。

仙石秀久は戸次川での失敗後、小田原の戦功と小諸復帰があるため対象外。洲賀才蔵・山田元義・加藤明成・六角義治・天野元景・松平忠直は、所伝の相違・責任関係・挽回の評価に留保があるため一律の全能力低下を発動しない。その他の旧 `failure_only` は、従来の根拠だけでは独立した重大失態と挽回なしを認定できず、項目別評価を用いる。

史料追加後も、全能力低下は出典と個別レビューのある人物だけに適用する。全能力が低いことを、本人の史実上の全ての能力が測定されていたかのようには記述しない。
