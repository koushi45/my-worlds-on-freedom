# 1546年の所属と配置のゲーム設定

ユーザー指定により、全1598人の立場を「大名・大名家一門・武将・浪人・元服前」に統一した。細かな史料上の立場は `historical_role`、判断理由は `historical_reason` に保持する。未誕生・故人・生存不確実は立場と別の `availability` で管理し、役割の分類によって生存や元服を確定しない。

今回調査した100人は、故人2人を除く98人に配置を設定。所属が分からない人物は `house_id=null` のまま浪人とし、`district_key` に地域の手掛かりから選んだ郡を保存する。配置によってその郡の領主へ仕えた扱いにはしない。原典の判断を変更したのではなく、ゲーム開始位置を設定したものである。

|人物|所属|立場|配置|
|---|---|---|---|
|森可成|不明|浪人|織田信秀系の候補郡から固定シードで抽選|
|市橋長利|斎藤家（美濃）|武将|既存の斎藤家候補郡内|
|丹羽氏勝|織田家（信次）|武将|尾張国・海東郡（深田城を手掛かりに設定）|
|生駒親正|不明|浪人|美濃国・可児郡（土田近辺）|

信次の家中は別ID `oda_nobutsugu` とし、上位の信秀家との関係を保持。深田城の記事は1552年、守山入城は1555年であり、1546年の領地採用はゲーム設定。既存の清洲・岩倉・信秀系の所属は統合しない。[織田信次の経歴](https://ja.wikipedia.org/wiki/%E7%B9%94%E7%94%B0%E4%BF%A1%E6%AC%A1)

`placement_house_id` は候補領域を提供した家で、所属ではない。特定地域への配置ではこの値を持たなくてもよい。根拠は `placement_reason`、配置方針は `placement_policy` に保持する。固定シードは再生成のたびに人物が移動するのを防ぐ。出生前・故人は開始時未配置を維持。拘禁・人物同定の問題がある人物は配置しても出仕可能に変更しない。

再生成は `python tools/officers/build_affiliations.py` → `python tools/officers/build_roster.py`。前者は史料調査を `affiliation_historical_1546.json` へ保存した後、`apply_affiliation_scenario.py` と `affiliation_scenario_locations.json` のゲーム設定を重ねる。実行時・一覧用は `affiliations_1546.json`。100人の画面は現在の設定と初回史料調査を併記する。
