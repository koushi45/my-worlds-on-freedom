# Officer Portraits Batch 03

This batch adds ten Miyoshi officer portraits as square PNG assets with real alpha transparency. The images contain no text.

## Reference workflow

1. Search the web for a person-specific historical or reconstructed portrait.
2. When a reliable person-specific portrait is unavailable, use a distinct Nobunaga's Ambition portrait as the visual fallback.
3. Use the selected image as the primary identity reference and `oda_nobunaga.png` only as the game's rendering-quality anchor.
4. Preserve distinctive facial proportions, apparent age, hair, and clothing cues from the primary reference while assigning a different pose and silhouette to each officer.

Person-specific reconstructed portraits were used for Jikkyu, Masanaga, Tamezo, Yoshioki, Nagayoshi, and Nagayasu. Soi uses his person-specific Nobunaga's Ambition portrait under the Masayasu name. Distinct Nobunaga's Ambition fallback portraits were used for Yoshifusa, Nagayuki, and Nagatora because a usable person-specific portrait was not found in the search results.

## Shared generation constraints

- Modern premium semi-realistic historical strategy-game portrait.
- True 1:1 composition and genuine alpha-transparent background.
- No environment, floor, frame, badge, floating crest, UI, writing, Japanese characters, watermark, or signature.
- Reference image 1 controls identity; reference image 2 controls finish only.
- Avoid repeated frontal arms-crossed poses and generic shared facial structure.
