# 近畿4城と推定連絡路の追加

2026-09-12のユーザー指定に基づき、既存250拠点を保持して以下4地点を城として追加。合計254拠点、近畿34拠点。旧国の指定を採用し、座標は城域の地域代表点とする。

|名称|旧国|経度・緯度|年代・位置の扱い|
|---|---|---|---|
|岸和田城|和泉|135.370786, 34.458760|戦国期城郭。後代の近世整備・復興天守の形状は再現しない|
|石山本願寺|摂津|135.528735, 34.686822|1580年退去・焼失。ユーザー指定による旧寺域の城表示。現在の大阪城跡代表点を推定地として用い、正確な寺域・本堂位置とはしない|
|高屋城|河内|135.609801, 34.548870|1575年廃城。ユーザー指定による旧城域の城表示|
|筒井城|大和|135.783556, 34.621591|1580年に順慶が郡山城へ移転。ユーザー指定による旧城域の城表示|

年代上の例外は `scenario_override` として記録し、拠点詳細で説明する。城分類と史実上の1582年の活動を混同しない。筒井城と郡山城は約3.2km離れた別城域として保持する。高屋城は簡略国境の1km以内だが、代表点は動かさず河内所属を保持。

位置はローカルのCODH『日本歴史地名大系』施設・地点項目データセット（2025-05-15）の各城跡項目を使用。石山本願寺だけは大阪市の推定地の説明と大坂城跡代表点を組み合わせた概略表示。データ帰属は doi:10.20676/00000456、CC BY 4.0。

## 推定連絡路

従来の3接続を7接続に置換し、合計285路線。4城それぞれに両方向の接続を持たせた。

- 尼崎―石山本願寺―堺
- 堺―高屋城―筒井城―郡山城
- 堺―岸和田城―雑賀

地形条件を変えず、新規・変更された接続を再探索。既存の未変更経路を保存する `--update-routes` は、地形入力と探索パラメータの不変、接続計画と出入口の一致を確認してから利用する。地形変更時は通常の全再生成が必要。

接続済み250拠点・陸路対象外4拠点。登録渡河629区間、接続グラフ1845区間。到達性・海湖回避・登録渡河・勾配・重複描画・旧道路データの不在を検証する。資料のない橋や道を史実として認定したものではない。

現在の正本は `data/editorial/settlements/` と `data/editorial/road_connections/plan.json`。`add_kinki_four_castles.py` は一度だけの移行記録であり、再実行せず正本を編集する。初期配分は250拠点時のものを保存し、その上に今回指定の4拠点を加算。画面の件数表示はデータから取得する。
