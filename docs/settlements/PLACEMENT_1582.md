# 1582年 拠点配置・全国250拠点版

全国254拠点。従来250拠点にユーザー指定の近畿4城を追加。年代・位置の例外は各拠点の詳細に明記。

全地点は地域代表点。原図の位置合わせ・曲輪・岸壁の精密比定は未実施。推定の印と詳細欄に確認状況を表示する。

「拠点一覧」で地域・種類・名称を絞り、選択した地点へ移動。「保留も表示」で調査候補を確認する。城・集落・港は別々に切替可能。
