For all ten, the individual reference was searched before generation. Named references were supplied to the image-generation tool for the three verified game portraits. For the other seven, prompts explicitly restricted the supplied game portrait to period costume and visual style and required a distinct original face. All generated portraits were visually inspected. The ten files are square, `Format32bppArgb`, and transparent at the upper-left corner.
