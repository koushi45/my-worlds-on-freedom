# 1546年開始時の支配家・統治担当

支配家、大名・領主、統治担当者、任命根拠はゲーム進行・領有境界・セーブ用の内部台帳として保持する。通常ゲーム画面では左側の統治情報パネル、検索ボタン、詳細表示を生成しない。地図クリックは郡または拠点の選択だけを更新し、統治情報を画面へ表示しない。

## 収録と設定方針

709郡と採用済み254拠点を収録し、採用保留3拠点も区別して台帳に保持する。統治担当の個人名を設定したのは662郡・213拠点（保留分を含む）。残る47郡・44拠点は、自治・担当者未詳・幼少当主・未成立等を区別する。架空の人物を史実の城主として追加してはいない。

1. 既存の1598人の武将設定を第一優先とする。現行の所属家・立場・活動可否・配置郡・明示された役職を参照する。新しい武将設定と古い家台帳が競合する場合は、新しい個人設定を優先する。
2. 配置された大名、同家の武将、家別配置候補を順に確認する。個人設定で郡の代表支配家を決めたものは191郡、家別配置候補から43郡。
3. 残る475郡には家の活動圏・地域資料から暫定のゲーム支配家を設定する。競合する候補も保持する。配置候補は史実の郡全域領有を証明する資料ではない。
4. 同家・同郡の活動可能な武将を優先し、政治・統率の順で統治担当を任命する。該当者がいなければ同家の他郡の武将を兼任させる。史実で確認した官職とゲームの任命は表示を分ける。幼少・元服前・故人・未誕生の武将を実務担当にしない。
5. 個人設定で不足する拠点帰属・役職・成立年代について自治体・博物館等の資料を補足した。実名を裏付けられない現地担当は未詳とし、名簿外の参考当主には武将IDを捏造しない。

全郡の1546年の排他的領有・現地代官を史料で確定したものではない。郡境は既存の比較用・合併済み区画を使用するため、史実上の郡と完全には一致しない。拠点の所在郡は既存地図の照合候補を利用し、63拠点は未解決または複数候補。近い郡へ強制所属させない。郡の代表支配家と拠点支配家が異なる場合も明記する。

## 個別調整と判断資料

栃尾城は既存設定から城主を上杉謙信（長尾景虎）、大名を長尾晴景として区別。[長岡市の資料](https://www.city.nagaoka.niigata.jp/kankou/rekishi/ijin/hataage.html)も参照。黒井城の荻野秋清、岩村城の遠山景前などは現行武将の設定を優先している。岩村の武田家所属はゲーム設定を優先したもので、1546年の従属時期の歴史的確定とは区別する。

水戸城は[水戸市立博物館の江戸氏資料](https://museum-mito.jp/exhibition/5058.html)を参照し江戸家とした。志布志は[志布志市の城史](https://www.city.shibushi.lg.jp/soshiki/22/1520.html)から豊州島津家とする。堺は[堺市の環濠都市資料](https://www.city.sakai.lg.jp/kanko/rekishi/bunkazai/bunkazai/isekishokai/kangotoshi.html)を参照し会合衆による自治運営とした。これらを後年の大名領へ一括して遡及しない。

1582年向けの拠点地図を引き継いでいるため、安土・坂本など14拠点は1546年時点で未築城・未開港と表示し城主を任命しない。金沢御堂は1546年内成立・月日未詳として区別する。地図上の記号自体は将来の拠点位置の参考として残る。資料一覧と個別の判断は検索台帳の「判断・出典」、生成データの `sources`、ルールファイルに記録した。

## データと再生成

- [検索付き全件台帳](register_1546.html)／[Markdown台帳](REGISTER_1546.md)
- ゲーム入力：`data/derived/governance/governance_1546.json`
- 担当未設定・競合の一覧：`data/master/governance/review_1546.json`
- 調査と例外ルール：`tools/governance/rules_1546.py`
- 再生成：`python tools/governance/build_governance.py`

既存武将・家台帳・郡・拠点原本は編集せず、入力SHA256を保持する。実行中の領有データも武将の生涯説明と分離した。現段階では開始時設定の表示までで、時間経過に伴う家督交代・寿命・築城・自動任命・領土移転は実装しない。

## 検証

Pythonの6テストで全件対応、入力整合、担当者ID・所属家・活動年代、未築城・幼少当主等の例外、所在郡候補、再生成一致を検証する。

Godotの統合テストで通常ゲーム起動、709郡・257拠点の読込、大名名検索、城主と大名の区別、自治・未築城表示、海上選択、停止状態の維持を確認する。実描画環境では地図の拠点をマウスイベントでクリックして詳細を開き、郡・拠点のスクリーンショットを確認する。既存の時間システムの回帰テストも実行する。

配布は `builds/windows-governance/MyWorldsOnFreedom.exe` と同フォルダのPCKを一緒に使用する。

2026-09-13の結果：Python 6件すべて成功。Godot統治テストはヘッドレス・実描画とも失敗0、時間システムの回帰テストも失敗0。実描画の郡・栃尾城の画面を確認済み。Windows Unconfirmedのリリース書き出し成功、配布EXEのヘッドレス起動（600フレーム）もエラーなし・終了コード0。画面記録とログは `builds/qa/governance_*` に保存した。
