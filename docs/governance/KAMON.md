# 郡中央の家紋表示

2026-09-14。郡名を描かず、表示倍率にかかわらず統治データの `house_id` に対応する家紋を郡の代表点へ表示する。家紋レイヤーを拠点名より前面に置き、重なっても家紋を省略しない。家紋は郡面積の4乗根に応じて基準28画面pxから拡縮し、極端な差を避けるため24～44.8画面pxに制限する。白い家紋を載せる円形背景には、その支配家のテーマカラーを用いる。

領有境界は白1.4px、色帯は内側へ9pxのフェード。色帯は tools/build_territory_fades.py で元ポリゴンから内側距離ごとの領域を切り出し、重複しない三角形へ分割する。全742領域について面積一致・外側へのはみ出し・三角形面積を生成時に検査する。実行時は境界からの距離で透明度を計算し、画面色の読み戻しや線分の押し出しを行わない。共有境界で隣の色が上書きしたり、接合部で帯が切れたりする原因を除いた。島4郡は従来どおり専用帯を表示しない。

50～200%では66の旧国境と国単位の内向き色帯を表示し、200%を超えると676郡の郡境・郡単位色帯へ切り替える。各国では国ポリゴンの面積中心に最も近い所属郡を代表郡とし、その郡の現在の支配家を国の支配家として色を決める。国の家紋は国ポリゴンの中心（中心が外へ出る凹形状では代表郡の代表点）へ表示する。

国または郡を選択しても境界線の色は変更しない。選択面だけに支配家のテーマカラーを重ね、透明から最大42%へ徐々に塗り、再び透明へ戻る2.4秒周期の演出を選択解除まで繰り返す。選択面は既存の国・郡ポリゴンをそのまま使い、白い境界線を最後に描くため、演出中も境界の表示色と形状は変わらない。

## 大名家テーマカラー

外交関係による4色ではなく、`data/derived/governance/house_theme_colors_1546.json` に189家それぞれの固定色を持つ。武田家は赤、伊達家は仙台市博物館所蔵の黒漆五枚胴具足に基づく黒を固定する。その他の主要家は家ごとの識別イメージを初期値とし、残りは緑・青・赤・黄・紫・橙・青緑など24色のパレットから隣接関係を考慮して割り当てる。

`python tools/build_house_theme_colors.py` は676郡から支配家同士の隣接グラフを作り、現在領有する151家・342隣接組について同色および近似色の隣接がないことを検査する。テーマ色はプレイヤーがどの家を選んでも変化せず、国表示、郡表示、領有色の半透明塗りで共通して使う。

## 家紋素材と未詳表示

日本語Wikipediaの各氏族ページで代表画像に指定された画像を取得し、Wikimedia Commonsの作者・ライセンス・ファイルページを `assets/kamon/index.json` に記録する。元画像がラスターの場合も512pxのCommonsサムネイルから輪郭を抽出し、ゲームには単色SVGだけを同梱する。分家は同じ氏族の家紋を共有する。加えて、発光大王堂の戦国武将家紋一覧で同家・同系統を照合できた14家、ユーザー指定による雑賀鈴木家の八咫烏、家名と「家紋」で個別に検索して人物・地域まで一致した14家を採用した。再利用可能な図柄はCommons素材から生成し、該当する図がない小野寺・祁答院・宗像・二階堂の4家は閲覧した伝統紋の図を単色輪郭パスへ再構成した。家紋の同定ページと図形参照URLは各家の台帳項目に保存する。

現在、領地を持つ151勢力すべてに表示先があり、132勢力がCommons由来、4勢力が個別参照図から再構成した家紋、15勢力が未詳表示である。国人連合・寺社・地域仮置き、または今回の参照先で代表家紋を確認できなかった家には、誤った家紋を割り当てず「！」の中立紋を表示する。対馬の宗氏も、家紋を確認するまではこの未詳表示を用いる。家紋は塗り分けのON/OFFにかかわらず白で描画し、暗色円盤で地形・領有色とのコントラストを保つ。素材の再生成は `python tools/generate_kamon_assets.py`。

参照起点：<https://commons.wikimedia.org/wiki/Category:SVG_Japanese_family_crests>。個別の作者・ライセンス・原ページは `assets/kamon/index.json` の `assets` に保存する。
