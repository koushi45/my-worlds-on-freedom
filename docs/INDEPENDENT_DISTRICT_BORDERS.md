# 国境から独立した郡境

国境に合わせて郡を閉じる旧表示処理を通常ゲームで使用しない。634郡は工程Cの切り取り前の比較形状から復元し、既存の合併対応を適用する。独立した元形状がない75の暫定区画は現形状を保持する。709郡のID・所属家・担当者は保持し、国境での切り取り、国境への吸着、国境との重複線の省略を描画処理から分離した。

描画順は国境（20）、郡境の破線（21）、領有の色付き枠線（22）、郡名（23）、拠点（24）。国境を消さず、重なる箇所では郡境を上に描く。郡の外周も独立して描くため、国境や海岸線の位置と異なっていても表示する。自領・同盟・敵対の色分けも新しい郡形状を使用する。

クリック判定・検索用の範囲・ラベル位置を同じ独立形状に合わせた。国境を越えた部分でも元の郡として選べる。境界許容範囲に複数郡が入った場合は、クリック位置から表示上の郡ラベル位置が最も近い一郡へ決定的に絞り込む。選択した郡は同じ輪郭を黄色で強調する。国名・家の所属はメタデータとして保持し、線の切り取りには使用しない。

これらの郡は後世比較データを含む既存ゲームの暫定区画であり、1546年の史実上の郡境を確定する変更ではない。国境データ原本、従来の郡原本、武将・統治台帳は編集していない。既存セーブの郡IDはそのままロード可能。

## 再生成と検証

- `python tools/build_independent_districts.py`：元形状と合併対応から独立形状を生成。
- `data/derived/scenarios/independent_districts_1546.json`：709郡の形状・範囲・ラベル、参照元SHA256、復元方法。
- `python tests/base_map/test_independent_districts.py`：ID全件、閉区画の妥当性、ラベル包含、国境を越える8箇所を検証。
- `tests/base_map/godot/test_independent_districts.gd`：描画順、旧クリップ済みバッチの停止、8箇所のクリック判定、平面・立体の一致を検証。

Python 2件成功、Godot実描画の検証は失敗0。平面・立体の画面を `builds/qa/independent_district_flat.png` と `independent_district_tilt.png` に保存し、国境を跨ぐ郡の輪郭を確認した。開始・保存・ロードの回帰テストも失敗0。追加の形状準備中はゲーム時間を進めず、タイトルでは従来どおりマップを読み込まない。

配布先：`builds/windows-independent-districts/MyWorldsOnFreedom.exe`。同じフォルダのPCKも必要。
