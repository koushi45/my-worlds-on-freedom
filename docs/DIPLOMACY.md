# 外交

評定の「外交」から、領地を持つ他家を選んで行動する。家名検索に対応する。

## 関係と友好度

- 関係は中立・同盟・敵対の3種類。地図の勢力表示と軍事行動に反映される。
- 友好度は家ごとの方向付きの値で、-100～100。外交画面には相手から見た友好度とこちらから見た友好度を表示する。
- 開始時の同盟は双方 +80、敵対は双方 -80、未設定の家は 0 から始まる。
- 同盟提案と停戦提案の受諾は、相手から見た友好度で判定する。

## 行動

| 行動 | 条件・効果 |
| --- | --- |
| 関係改善の使節 | 1家につき1か所へ派遣。毎月1日に相手からの友好度 +5。100になると帰還。別の家へ派遣すると派遣先を切り替える。 |
| 贈物 | 金銭100を払い、相手からの友好度 +20。 |
| 同盟提案 | 中立・停戦中ではない・相手からの友好度40以上。同盟を結び、双方の友好度 +15。 |
| 同盟破棄 | 関係を中立にし、相手からの友好度 -40、威信 -10。 |
| 侮辱 | 同盟相手以外に可能。相手からの友好度 -25。 |
| 宣戦 | 中立・停戦中ではない。敵対に変更し、相手からの友好度 -50、威信 -10。 |
| 停戦提案 | 敵対・相手からの友好度 -20 以上。中立に戻し、360日間の停戦を設ける。 |

使節の派遣・帰還を除く同じ相手への外交行動には30日の間隔が必要。敵対する城への攻撃でも宣戦と同じ友好度・威信の変化が起きる。停戦中は攻城できない。

友好度、使節、停戦期限、最後の行動日はセーブデータに保存される。
