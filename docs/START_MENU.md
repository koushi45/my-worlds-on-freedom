# 開始画面・セーブ・ロード

開始画面は山城と山並みの静止画。表示するのはスタート、ロード、辞典、オプション。辞典は「準備中」の無効ボタンとする。オプションは開始画面とゲーム中メニューの両方から開ける。マップシーン・標高・タイルはスタートまたはロードを実行するまで読み込まない。

Windows版の初回起動サイズは1920×1080。オプションでは1280×720、1920×1080、2560×1440、3840×2160（4K）を選択し、適用時に即座にウィンドウをリサイズする。選択値は `user://display_settings.cfg` に保存して次回起動時に復元する。

メインマップでは Savfk の「Eight Mountains」と Alexander Nakarada の「Rise Again (Alternative Version)」を曲の終了ごとに交互再生する。いずれも作者の公式配布ページで CC BY 4.0 と明記された音源をOGG Vorbisへ変換して同梱し、曲名・作者・配布元・ライセンス・改変内容を各 `assets/audio/*_LICENSE.txt` に記録する。オプションではBGM音量を0～100%で変更でき、初期値は40%。解像度と同じ設定ファイルへ保存し、再生中にも即時反映する。

ボタン、一覧項目、スライダー操作と、マップ上の拠点・国・郡の選択には、Breviceps の「Click / Cursor SFX - Scroll through files / folder / cabinet」（Freesound sound ID 445972）を共通の操作音として使う。効果音音量はBGMとは独立して0～100%で変更でき、初期値は100%。CC0によるゲームへの同梱・商用利用が可能であることを確認し、素材名・作者・配布元・ライセンス・ハッシュを `assets/audio/ui_click_breviceps_LICENSE.txt` に記録する。

郡を選択した時だけ左側へ郡情報ウィンドウを表示し、郡名の直下に1546年統治台帳上の支配者名を表示する。表示された郡名はボタンとして操作でき、クリックすると郡名だけをOSのクリップボードへコピーし、ウィンドウ内に完了メッセージを表示する。国・拠点・空白地点の選択時はこのウィンドウを隠す。

スタートで大名家の一覧を開く。既存の1546年統治台帳から、領有郡がある140家を選択可能にした。自治組織・帰属未詳の集合は選択対象外。家名・当主名を検索でき、当主と郡数を表示する。選択後は1546年1月1日、通常速度で開始し、自領の郡付近へカメラを移動する。

## 領有表示

- ゲーム画面左下には現在のマップ拡大率だけを表示する。プレイ中の大名家名と、自領・同盟・敵対・その他の凡例は表示しない。
- 領有境界は白線と、その領地側へ入る支配大名家のテーマカラー帯で区別する。
- 新規開始時のマップ拡大率は50%とし、50%未満には縮小できない。
- 選択した国・郡は境界線を変色させず、その面だけをテーマカラーで徐々に塗って透明へ戻す演出を繰り返す。
- 郡をクリックした場合だけ、画面左側に選択中の郡名を表示する。国・拠点・選択対象外をクリックした場合は郡名ウィンドウを閉じる。

各郡を個別に囲み、背景と区別する暗色の縁取りを付けた。平面・立体の投影に対応し、ズームしても画面上の太さを保つ。投影済みの線を再利用し、画面外は描画しない。開始時の郡ポリゴンから表示用の輪郭を生成し、郡原本は変更していない。

外交関係は対称の家IDペアとして保存する。既存プロジェクトには独立した外交データがなかったため、今回の初期設定は武田・今川、山内上杉・扇谷上杉の同盟と、北条・両上杉の敵対の計4組。武田・今川は[上田市の歴史資料](https://museum.umic.jp/ikushima/history/takeda-kakawari.html)、河越の関係は[川越市の資料](https://www.city.kawagoe.saitama.jp/shisei/mayor/1018956.html)を参照したゲーム開始時の設定。全国の外交関係を確定したものではなく、未設定の相手を自動的に敵としない。データは `data/derived/scenarios/diplomacy_1546.json` で追加・調整できる。

## ゲーム内メニュー

右上の時間欄の下にメニューボタンを追加。Escでも開閉する。セーブ、ロード、辞典、オプション、スタートメニューに戻る、ゲーム終了、ゲームに戻るを配置した。メニュー中はゲーム時間と地図操作を停止する。戻るとメニューを開く前の停止状態を維持し、メニュー中の時間を日付へ加算しない。

解像度とBGM音量は `test_display_options.gd` で4候補、標準値、1280×720への実リサイズ、4K選択、40%の音量初期値、即時反映、設定保存を検査する。ゲーム中からの表示とEsc復帰は `test_start_session.gd` で検査する。

Escは統治情報欄が開いていてもゲームメニューを優先する。セーブ・ロードの一覧ではメニューへ戻り、確認ダイアログではキャンセルする。タイトルへ戻る・終了・ゲーム中のロード・セーブの上書きには画面内で確認を出す。

## 保存する情報

5スロットに、選択大名家、年月日、経過日数、1日未満の進行、速度、手動の停止状態、全郡・全拠点の支配家・大名・統治担当、外交関係、カメラ位置、ズーム、立体表示を保存する。閉じてから次に起動してもタイトルのロードから続行可能。

Windowsの保存先は `%APPDATA%/Godot/app_userdata/My Worlds on Freedom/saves/slot_1.json` ～ `slot_5.json`。JSON形式のバージョン1。整合チェックとSHA256を検証し、不正な日付・不明な家/人物・欠けた領土・破損データを拒否する。現在のゲームを破棄するのは検証成功後。一時ファイルへの書き込み後に確定し、上書き前のデータを同名 `.bak` に保持する。バックアップの自動復旧UIは未実装。

以前のビルドにはセーブ機能がないため、既存ゲームからのセーブ移行はない。武将伝記など不変の元データは保存ファイルに複製せず、領有・担当の実行時状態を保存する。

## 構成・再生成

- `scenes/start/start.tscn` / `scripts/game/start_screen.gd`：新しい起動シーン。
- `assets/ui/title_landscape.svg`：コードで作成した静止画。
- `scripts/game/game_session.gd`：マップを事前ロードしないセッション管理・保存検証。
- `scripts/game/game_menu.gd` / `save_slots.gd`：ゲームメニューと保存一覧。
- `scripts/game/territory_borders.gd`：領有枠線。
- `python tools/session/build_session_data.py`：統治台帳と郡ポリゴンから軽量家一覧・輪郭を再生成（Python / Shapely使用）。

通常の起動シーンをタイトルへ変更した。開発用 `-- --developer-ui` 指定時だけ従来のマップ開発画面へ直接進む。

## 検証

`tests/base_map/godot/test_start_session.gd` で、タイトル時のマップ未読込、家選択、3種類の枠線分類、Esc、停止と再開、セーブ画面、日付繰越、上書きバックアップ、破損拒否、タイトルへの帰還、マップノード解放、再ロードを検証した。領有と外交を初期値から変更して保存し、初期値に戻すだけの実装では通らない復元テストにしている。テスト保存先は毎回専用フォルダで、利用者のスロットを使わない。

ヘッドレスおよび実描画で失敗0を確認。開始画面、大名家選択、領有枠線、ゲームメニュー、保存一覧のスクリーンショットを `builds/qa/start_*.png` に記録。配布版は `builds/windows-start-menu/MyWorldsOnFreedom.exe` と同フォルダのPCKを一緒に使用する。

Windowsリリースの書き出し成功。配布EXEは実描画で180フレームのタイトル起動を確認し、マップ読込ログなし・エラーなし・終了コード0。配布PCKをGodotで読み込む追加テストでも、タイトルの分離、大名家選択後のマップ起動、枠線、メニューの生成が成功した。既存の時間操作は実描画で失敗0、統治情報の回帰テストも失敗0。ログは `builds/qa/start_*` に保存。
