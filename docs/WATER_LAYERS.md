# 河川・湖の独立レイヤー

川と湖を標高の上へ追加しました。現在は選定した主要44河川を表示対象にしています。左側の「主要河川」「湖」で個別に切り替えられます。「琵琶湖へ移動」で琵琶湖周辺を詳細表示します。標高レイヤーと平面・立体表示の切替にも対応します。

地図上の湖名ラベルは表示しません。湖の形状・管理用名称・「琵琶湖へ移動」ボタンは保持しています。

最新版Windows: `builds/windows-latest/MyWorldsOnFreedom.exe`（同じフォルダーの `.pck` も必要）。旧ビルドの削除は自動承認審査に拒否され、未実行です。一括削除と、固定パスの旧ZIP1個に範囲を狭めた削除の両方が `blocked by policy` で拒否されました。対象一覧は最新版フォルダーの `cleanup_plan.json` に記録しています。

## 主要河川の表示

利根川、信濃川・千曲川、淀川・宇治川・瀬田川、木曽川、筑後川など主要44河川を明示的に指定しました。川面データの大きい未描画候補から鬼怒川・米代川・関東の那珂川を追加しました。流量・川幅を測定して自動分類したものではありません。採用一覧と原本区間IDは `data/derived/hydrography/major_rivers_selection.json`、選定定義は `tools/select_major_rivers.py` に保存しています。

名称付き区間と、その間をつなぐ同一ネットワークの名称不明区間を表示します。琵琶湖の南端から宇治川上流までの名称不明区間（原本ID 1155）は、瀬田川に相当すると確認して明示的に追加しました。これにより、琵琶湖→瀬田川→宇治川→淀川→大阪湾の経路を表示します。渡良瀬川・桂川・只見川などの支流、江戸川などの分流は表示しません。原本の名称情報に依存するため、名称付き区間より先の源頭部などは自動延伸せず、全流路長を保証するものではありません。

線は461区間を表示し、4,120区間を非表示にしました。非表示の元データは保持し、すべての拡大率で非表示フラグを尊重します。広い川を表す面も分類し、採用した64面は主要河川スイッチに連動します。非採用の河川面を湖スイッチ経由で表示することはありません。湖・貯水池は引き続き表示します。

追加候補の判断には、原本で河川面として収録された面積を目安にしました。未採用の名称付き河川面には一ツ瀬川 2.92 km²、番匠川 2.72 km²、芦田川 2.46 km²、高瀬川 1.84 km²、大和川 1.21 km²などがあります。これは川幅の実測値ではなく、現在の広域用データでの描画上の目安です。大和川の現代河道は戦国期と異なるため、追加時には歴史的な河道を別途確認します。

- 琵琶湖から大阪湾への流路: [国土交通省 近畿地方整備局・淀川流域の概要](https://www.kkr.mlit.go.jp/yodogawa/know/summary/ryuiki/)
- 大和川の1704年の付け替え: [国土交通省・日本の川 大和川](https://www.mlit.go.jp/river/toukei_chousa/kasen/jiten/nihon_kawa/0609_yamato/0609_yamato_01.html)

## 出典と範囲

国土地理院「地球地図日本 第2版 水系」（2011年公開）の `riverl_jpn` と `inwatera_jpn` を採用しました。

- 出典: https://www.gsi.go.jp/kankyochiri/gm_jpn.html
- 取得ZIP: https://www1.gsi.go.jp/geowww/globalmap-gsi/download/data/gm-japan/gm-jpn-hydro_u_2.zip
- 利用条件: 国土地理院コンテンツ利用規約／公共データ利用規約 PDL1.0。出典・加工の表示をゲーム内と同梱の `WATER-ATTRIBUTION.md` に記載。
- 日本のゲーム対象範囲へクリップ後、川4,581区間、湖などの内陸水域804ポリゴン。区間数は河川の本数ではありません。
- 琵琶湖、霞ヶ浦、猪苗代湖、諏訪湖、洞爺湖、支笏湖などを含みます。
- 約1:1,000,000の広域用に一般化された現代の水系です。細流すべての収録や、戦国期の河道・湖岸を復元したデータではありません。原本で名称不明の水域は推測で命名していません。

## 基盤・標高との整合

原本のJGD2000地理座標（EPSG:8994）から、承認済み陸地と同一のLCC・8192座標へ変換しました。基盤ポリゴン、旧国境界、標高原本は変更していません。河川と湖を陸地内部にクリップし、湖を海と別IDで管理します。

川の湖面内部分を取り除き、線が湖面を横切らないようにしました。湖の穴（島）を維持し、地形メッシュの16座標単位の格子・対角線で湖面を分割して三角形化しました。川の線も同じ地表変換を使用するため、立体表示を切り替えても地面からずれません。

描画順は地形→湖→川→政治境界。拡大時は川を読み取りやすくし、広域表示では線を細く薄くします。画面外の水系を描画対象から外し、投影済み形状をキャッシュします。平面・立体切替時にキャッシュを更新します。

成果物:

- `data/derived/hydrography/water_registry.json`: 描画ベクター、原本ID、水域の種類、湖の穴と三角形。
- `data/derived/hydrography/hydrography_manifest.json`: 原本・基盤・出力のSHA-256、座標変換、件数。
- `scripts/map/water_layer.gd`: 川・湖の独立した描画ノード。
- `tools/build_hydrography.py`: 再生成。NumPy、PyProj、Pyogrio、Shapely（制約付き三角形分割対応）が必要。取得済み原本を再利用し、ゲーム実行時の通信は不要。
